# 解决取消订单缺少 reason 参数的问题

## 问题分析

用户在取消订单时遇到 "缺少必需参数：reason" 的错误。
经过代码分析：

1. **后端** (`RecycleOrderService.php`)：`cancel` 方法明确要求 `$data` 数组中包含 `reason` 字段。
2. **前端** (`list.vue`)：在 `handleAction` 方法的 `order_cancel` 分支中，目前仅使用了 `ElMessageBox.confirm` 进行简单的确认，调用 `updateRecycleOrder` 时仅传递了 `{ action: "order_cancel" }`，**缺失了** **`reason`** **参数**。

## 解决方案

修改前端代码，将简单的确认对话框改为输入框，要求用户输入取消原因，并将其传递给后端。

## 实施步骤

编辑文件：`admin/src/addon/recycle/views/recycle_order/list.vue`

1. 找到 `handleAction` 方法。
2. 修改 `if (action.key === "order_cancel")` 代码块。
3. 将 `ElMessageBox.confirm` 替换为 `ElMessageBox.prompt`，允许用户输入取消原因。
4. 在调用 `updateRecycleOrder` 时，将用户输入的 `reason` 添加到参数中。
5. 优化错误处理，避免用户点击"取消"时弹出错误提示。

### 代码变更预览

```typescript
// 修改前
if (action.key === "order_cancel") {
  await ElMessageBox.confirm("确定要取消该订单吗？", "提示", {
    confirmButtonText: "确定",
    cancelButtonText: "取消",
    type: "warning",
  });
  await updateRecycleOrder(row.id, { action: "order_cancel" });
  // ...
}

// 修改后
if (action.key === "order_cancel") {
  try {
    const { value: reason } = await ElMessageBox.prompt("请输入取消原因", "取消订单", {
      confirmButtonText: "确定",
      cancelButtonText: "取消",
      inputPlaceholder: "请输入取消原因",
      inputValidator: (value) => {
        if (!value || !value.trim()) {
          return "取消原因不能为空";
        }
        return true;
      },
    });
    
    await updateRecycleOrder(row.id, { 
      action: "order_cancel", 
      reason: reason 
    });
    ElMessage.success("订单已取消");
    await getList(pagination.value.page);
  } catch (error) {
    if (error !== 'cancel') {
      throw error; // 抛出非取消的错误，由外层 catch 处理
    }
  }
}
```

此外，我还会微调外层的 `catch` 块（如果需要），以确保用户体验流畅。
