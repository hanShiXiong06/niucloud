1. **联动出纸实拍。** 同一台测试机完成录入保存，镜头接着拍打印机出标签、贴到对应设备上。不能用标签编辑器预览代替实际打印成功，也不要剪成“刚插线就出纸”。正文已经留出位置。

## 本次确认的能力边界

| 对外表达 | 代码依据与前提 |
| --- | --- |
| 电脑端读取设备并辅助填写基本资料 | `admin/src/addon/hsx_recycle/components/device-entry/useLocalDevice.ts` 与 `DeviceEntryList.vue`；依赖本地读机服务，苹果设备需满足连接、解锁、信任等条件，实际可读字段以设备和工具为准 |
| 自动匹配标准型号并加载模板 | `DeviceEntryList.vue` 中 `matchModelToCategory()` 与 `applyResolvedModelNode()`；不能唯一匹配时要求人工确认，不保证任意新品自动识别 |
| 保存设备后联动标签打印 | `niucloud/addon/hsx_recycle/app/service/admin/order/RecycleOrderDeviceService.php` 在数据库提交后触发 `device.sign.saved` |
| 打印前提 | `PrinterSceneDict.php` 与 `RecyclePrintSceneService.php`；设备标签场景需启用、开启自动打印、选择“设备签收保存后”触发节点，并有可用打印机、模板及通道。内置场景默认并不自动开启 |
| 打印结果可检查 | `RecyclePrintTriggerService.php` 通过任务执行，记录成功、失败或跳过结果；发起任务不等于已证实实物出纸 |
| 后续移动端可继续处理 | `site-uniapp/src/addon/hsx_recycle/pages/order/components/CheckDevicePopup.vue` 与 `pages/check/scan.vue`；沿用设备资料，按权限和状态开展人工操作，不意味着移动端能直接用 USB 读取苹果手机 |

## 发布用语

- 推荐：“读取设备，保存后联动打标签，后续质检继续用这份资料。”
- 避免：“插上就自动入库”“自动完成质检”“所有型号都能识别”“节省 80% 人工”。没有实际测量的数据不写。
- 新品型号和模板及时维护可以另作补充内容；具体型号、匹配结果与模板完整度应现场核对后再宣传。
- 交付承诺写清范围：独立站点、基础配置、读机与打印接通、约定业务流程陪跑。不承诺所有客户环境都零故障。
