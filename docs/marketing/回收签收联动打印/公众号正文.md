# 做二手机回收，你招的是验机员，还是串号录入员？

我自己做二手机，也写系统。有件事，我一直觉得不对劲。

一台手机到了店里，签收抄一遍串号，电脑填一遍资料，打标签再输一遍。到了质检，还得翻记录，确认是哪台机器。

人一直没闲着。但这些忙，有多少是在重复做同一件事？

**员工不是不够努力，是流程在让他反复搬运信息。**

## 我想先把这件小事改掉

不用先谈什么数字化转型。就从一台苹果手机的签收开始。

读机工具接好，手机解锁并信任电脑，在签收页面读取设备。能获取到的串号、容量、系统、电池信息，直接回填；匹配标准型号后，带出对应的质检模板。

有些信息读不到，或者型号不能确定，就留给人核对。该省的是重复录入，不是必要的确认。

![签收录入入口：读取设备、选择标准型号、保存集中在同一处。图为本地演示界面。](/Users/a123/Documents/1-work/niucloud/niucloud/docs/marketing/回收签收联动打印/images/01-签收录入入口.png)

## 关键是，保存以后，标签也跟着出来

提前把打印机、标签模板和签收自动打印配好，**每录入并保存一台设备，系统就自动发送标签打印任务。**

标签按模板取用这台设备已经保存的信息。

不用再打开另一个软件，把型号、串号重新敲一次；也不用一边看屏幕，一边照着抄。

**信息录进去了，标签接着用。不是换个地方，再录一遍。**

接下来做质检，设备的基本资料继续沿用，员工把精力放在检查机况、记录问题上。电脑可以处理，移动端也能承接质检操作，不必为了找一台机器的资料来回问人。

## 店里不一定缺人，可能只是重复劳动太多

我不想承诺装套系统就能省掉几个员工。

但我觉得，专业的人，不应该把时间耗在抄串号、找资料、反复填表上。

**好的系统，不是让员工多填几张表，而是让同一份信息，尽量只填一次。**

这也是我做这套回收系统的出发点。

我提供独立站点，也提供交付陪跑。读机怎么接、标签怎么打、员工怎么用，按约定流程一起跑通，不是给你一个账号就结束。
