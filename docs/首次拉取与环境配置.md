# 首次拉取与环境配置

本仓库交付业务源码及公共构建默认值，不随代码分发任何实例的数据库密码、支付证书、地图密钥或小程序绑定信息。

已有部署首次拉取这个版本前，请先把原 `niucloud/.env` 安全保存在仓库外。旧版曾跟踪这个文件；快进到新版本时 Git 可能移除旧的已跟踪副本，拉取后应恢复自己的配置。全新克隆不受此影响。

如果旧部署直接使用仓库里的支付证书、前端环境文件或应用清单，请在拉取前一并将该部署实际使用的配置安全备存在仓库外。支付证书由部署方单独配置，不要重新加入 Git。

- **PHP**：新实例参考 `niucloud/.example.env` 或运行项目安装程序，在部署环境独立配置 `niucloud/.env`。已有实例应保留原来的数据库连接和应用密钥，不要换成示例值。
- **PC 管理端**：默认使用同源 `/adminapi/`。分离部署时，在 `admin/.env.development.local` 或 `admin/.env.production.local` 设置 `VITE_APP_BASE_URL` 和 `VITE_IMG_DOMAIN`。
- **商城 H5 / 小程序**：在 `uni-app/.env.development.local` 或 `uni-app/.env.production.local` 配置相应环境。小程序不能使用浏览器同源地址，须使用在对应微信后台已配置的 HTTPS 域名（API 地址包含 `/api/`），并设置自己的站点编号 `VITE_SITE_ID`。
- **Nuxt Web**：在 `web/env/.env.dev.local` 或 `web/env/.env.product.local` 配置后重新构建。
- **App / 小程序构建**：`site-uniapp/src/manifest.json` 与 `uni-app/src/manifest.json` 保留平台配置结构；发布前由各自的构建流水线在工作副本里填入该应用自己的 AppID，以及实际使用的地图 SDK key。不要把填入后的值重新提交到仓库。
- **部署**：此提交不是网站发布或小程序提审。前端需使用本环境参数按项目说明重新构建；不要将仓库里的旧静态产物当作本次构建结果。
- **订单轨迹**：旧天地图独立页面不再使用固定会员令牌。查看轨迹请从已登录的商城订单详情进入。
