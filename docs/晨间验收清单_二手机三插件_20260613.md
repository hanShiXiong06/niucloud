**做了什么**
- 新插件 `niucloud/addon/hsx_finance/`，**完全独立、不碰核心、不跨插件读表**。
- 4 张表：应付 `finance_payable`、应收 `finance_receivable`、结算单 `finance_settlement`、核销明细 `finance_settlement_link`（`finance_` 前缀）。
- **折账核心**：`FinanceSettlementService` —— 折账=min(应付合计, 应收合计) 净额冲抵，余下一侧自动走现金，自动判定 **现金 / 折账 / 混合** 三种方式；FIFO 分摊核销；全程事务。
- **预演（preview）**：只算不写，前端确认弹窗先给你看"折账多少、现金付/收多少、什么方式"。
- **事件解耦**：消费 `FinancePayableCreated`/`FinanceReceivableCreated`（幂等落库）；结算后发 `FinanceSettlementCompleted`，业务/ERP 订阅更新展示。
- **接口**：余额看板、应付/应收列表、待结明细、结算预演、确认结算。
- **前端**：菜单"二手机财务 → 往来对账·折账"，页面 `board.vue` = 往来单位余额看板（应付/应收/可折账/净额）+ 折账结算弹窗（勾选→预演→确认），已双份同步、编译通过。
- README 含**生产者接入示例**（回收/销售如何发应付/应收事件）。

**怎么验收（建议顺序）**
1. 后台插件管理里**安装 hsx_finance**（建 4 张表）。
2. 进"二手机财务 → 往来对账·折账"——此时无数据是正常的（还没有生产者发事件）。
3. 想看效果可手动 insert 两条测试数据：同一 `counterparty_id` 下一条 payable(amount=4000)、一条 receivable(amount=5000)，刷新看板应显示"可折账 4000、净额 1000 我收"。
4. 点"去结算"→勾选两条→预演显示"折账 4000 + 现金收取 1000、方式=混合"→确认→两条都结清。
