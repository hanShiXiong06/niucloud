# ERP 化繁为简 · 模块地图 + 测试方法

> 目的:把现在十几个菜单、二十多个服务,收成一张"一眼能看懂"的图,
> 让任何人(尤其会计)都知道:东西在哪、谁找谁要钱、自己的活在哪。

---

## 0. 一句话看懂整个 ERP

> **整个 ERP = 一台设备的一生 + 它身上的钱。**

每台机一物一码,从进货到卖出,全程挂着两条线:
- **货的线**:进货 → 加工(定价/整备) → 卖出
- **钱的线**:应付(买它、修它) → 应收(卖它) → 结算(钱到位) → 核对(账确认)

把这两条线理顺,ERP 就清楚了。下面五大模块,就是这两条线上的五个站。

---

## 1. 五大模块(化繁为简后)

### 模块一 · 进货入库 「货怎么进来」
- **干什么**:回收/采购的机器登记入库、建立设备台账(一物一码)。
- **谁用**:采购 / 仓库 / 中台
- **产出的账**:**回收应付**(欠供应商的钱)
- **现有菜单**:入库工作台、手工建档入库、确认入库、设备中心 / 库存概览、仓库与库位
- **待办卡**:待入库、待确认

### 模块二 · 中台加工 「货怎么变好卖」
- **干什么**:质检拍照后定价;需要维修的走整备。
- **谁用**:定价员 / 整备负责人
- **产出的账**:**整备成本**(设备子账 + 应付整备方)
- **现有菜单**:销售定价、整备工作台
- **待办卡**:待定价、待整备、整备完工待确认

### 模块三 · 销售出库 「货怎么卖出去」
- **干什么**:卖给同行 / 商城,出库,生成展示单。
- **谁用**:销售 / 收银
- **产出的账**:**销售应收**(别人欠我的钱)
- **现有菜单**:出库管理、代下单收银台、设备调拨、出库退回
- **待办卡**:挂账待收款

### 模块四 · 财务结算 「钱怎么管」 ★核心
- **干什么**:把上面三块产生的应收应付,**收齐、付清、核对**。
- **谁用**:财务
- **两个核心动作**:**结算(打款/要账,动钱)** + **核对(复核确认,不动钱)**
- **现有菜单**:财务中心(往来汇总、应收/应付、应收应付待结、结算)、资金账户、记一笔收付、账目往来流水、(待加)经营支出+额外收入、核对
- **待办卡**:待收款、待付款、待结算、收款待核验、待对账

### 模块五 · 监管追溯 「怎么保证不出错」
- **干什么**:任意一台设备/一笔账,都能查到全链路;对账、看板。
- **谁用**:老板 / 财务 / 稽核
- **现有菜单**:串号追踪 / 设备全链路、按设备对账、账实校验、运营看板、AI 分析

> 另有**基础配置**(往来单位、仓库库位、角色与权限、收款设置)——是地基,不算业务流。

## 2. 一根主线:设备(关联性的答案)

五大模块不是五个孤岛,是**同一台设备**依次经过的五个站:

```
   [模块一]        [模块二]         [模块三]        [模块四]        [模块五]
   进货入库   →    中台加工    →    销售出库   →   财务结算   →   监管追溯
   回收应付       整备成本子账       销售应收       结算+核对       全链路对账
      └──────────────── 全部挂在「这台设备」身上 ─────────────────┘
```

**只要每笔账都挂在设备上(护栏4),这五块就自动连成一条可追溯的链。** 这就是"关联性"的全部秘密——不靠人记,靠设备这根线串。

---

## 3. 三大核心目标怎么落地

| 目标 | 怎么保证(机制,不靠人自觉) |
|---|---|
| **准确性** | 余额永远由真实流水自动算出,不手动改;核对只标记不删账(护栏1、2) |
| **完整性** | 每台设备全程在某个待办队列里,没走完不消失;漏一步就有人的卡上挂着 |
| **关联性** | 每笔账强制挂设备(交易账);设备子账 +/− 记录每一次成本/利润变化(护栏3、4) |

## 4. 怎么测(你最关心的)

业务复杂,但测试可以很简单——**用"一台设备走完一生"当剧本,逐站打勾。**

### 4.1 端到端主剧本(任务制,照着走一遍)
拿一台真机,从头走到尾,每步看一个检查点:

1. 入库 → 设备台账有这台 + 生成一笔**回收应付**(金额对、挂着这台设备)
2. 定价 → 有售价
3. 整备(可选)→ 设备子账多一条**整备成本** + 一笔**应付整备方**
4. 上架 → 商城能看到、可卖
5. 卖出 → 生成**销售应收** + 商城展示单(待支付)
6. 收款(结算)→ 应收结清、资金账户进钱、商城展示单变"已完成"、商品下架
7. 核对 → 财务打勾,这笔从"待核验"消失(但金额还在账上)

**每步就一个问题:这一步该产生的账,有没有、对不对、挂没挂在这台设备上。**

### 4.2 角色待办验收
每个角色登录,看自己的待办卡:**数字对不对、点进去是不是该处理的那批**。卡和实际对得上 = 这个角色的闭环通了。

### 4.3 三处对账(终极检查)
任意时刻,同一台设备/同一个往来单位,这三个地方必须对得上:

> **应收应付明细  ⟺  往来汇总  ⟺  资金账户流水**

对得上 = 账是准的;对不上 = 抓到一笔问题账(而不是手动抹平它)。

---

## 5. 怎么稳步往前(给你的定心丸)

有了这张图,**就不用"一大步往前迈"了**,改成:

- **一次只动一个模块**,动之前先说清"它产生哪笔账、挂哪台设备";
- **每次改动都配一段上面 4.1 的剧本**,改完照着走一遍,绿了才算完;
- **看板/对账(模块五)永远是你的安全网**——任何改动后,去 4.3 那三处对一下,对得上就放心。

化繁为简本身就是在降风险:**先看清五块和那根设备主线,之后每一步都是"在已知地图上挪一格",不是"往黑箱里再塞东西"。**
