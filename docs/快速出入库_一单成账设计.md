# 快速出入库（一单成账）

> 诉求：有时只是"走个账"——某台机器在我账上留一笔。快速选好**供货人**和**买家**,写好**进价/出货价**,一行一台、多台也行,只留关键信息(型号/IMEI)。入口放**运营看板首页**,人人可见。

## 一、底层落成（复用,不造轮子）

每台设备复用三段成熟逻辑,保证账货一致、可追溯：

1. **入库**(`ErpStandaloneInboundService::create`,business_type=purchase,供货人,进价,未付)→ 建最小资产 + 生成「**应付供货人**」(挂账)。
2. **翻为在库**:资产 `inventory_status → in_stock`(过账跳过仓库/库位/拍照,不关心库位)。
3. **出库**(`createOutbound`,settle_mode=later,买家)+ **回填价**(`fillPrice`,collect_now=false)→ 生成「**应收买家**」(挂账)。

> 两笔账默认都**挂账**(应付/应收均未结),后续在财务中心正常核销收/付款。设备过账后置「销售锁定(locked)」,可退。

## 二、ID 口径（关键,别传错）

- **供货人**:入库 `counterparty_id` = 对接人(ErpCounterparty.id)+ `counterparty_member_id` = member_id。前端 counterparty-select `value-field="counterparty_id"`,`@resolved` 取 member_id。
- **买家**:出库 `counterparty_id` = **member_id**(往来锚)。前端 `value-field="member_id"`。

## 三、逐行容错

每台独立 try/catch,失败不影响其它台,返回汇总 `{success_count, fail_count, total_buy, total_sale, total_profit, ok[], fail[]}`。前端回执显示成功/失败明细。

## 四、文件

- 后端:`app/service/admin/ErpQuickTradeService.php`、`app/adminapi/controller/QuickTrade.php`、`app/adminapi/route/route.php`(`POST erp/quick_trade/create`)
- 前端:`components/quick-trade/index.vue`(弹窗)、`api/quick_trade.ts`、`views/dashboard/index.vue`(运营看板首页「快速出入库」大按钮)。均已镜像到 `niucloud/addon/hsx_erp/admin/`。

## 五、扩展位（以后要的话）

- 现结模式:出库走 `fillPrice(collect_now=true, capital_account_id)` 即可当场收款入账、设备转「已售」。表单加"已收/已付"开关即可。
- 只入或只出:当前为"都填·直接购销过账";若要单边,放开校验、分别只走入库或只走出库。
- 设备状态:如需过账即「已出库」,把第 3 步改 collect_now 或直接置 outbound。

## 六、部署提醒

后端改动需重启 php-fpm(OPcache),前端需重新 build。
