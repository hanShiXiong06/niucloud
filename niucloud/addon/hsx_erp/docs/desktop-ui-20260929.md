# ERP 桌面界面调整与验证

## 范围

工作台、采购、采购退货、销售出库、销售退货、库存、盘点、应付、应收，共九个页面。

- 复用 hsx_components，新增 ERP 内的页面、表格和财务概览组件。
- 统一筛选、汇总、表格和分页的间距与信息层级，表格按可用高度滚动。
- 工作台压缩为核心指标、经营图表、财务待办和近期业务；页内汇总明确标注统计范围。
- PC 和 iPad 使用桌面布局；手机访问对应页面时进入已有移动管理页面。
- ERP 页面、当前页面内的弹窗/抽屉使用 Element Plus 主题变量。工作台图表随主题切换重绘。

## 应收、应付的信息层级

- 默认展示往来主体、状态、总额、已结算和剩余金额。
- 来源单号、ERP 关联单号、应收/应付编号、结算约定归入“单据与来源”，默认收起。
- 设备名称、规格、IMEI 和核对金额仍直接显示，不能因减少信息而影响核机。
- 设备行可以展开查看仓库等辅助资料；应付行保留采购时间和应付单号，应收行保留成本和利润。
- 结算记录单独折叠，保留已有流水、凭证等查看能力。
- 关闭、折账、收付款入口固定在抽屉底部。进入收付款表单时关闭详情抽屉，继续使用原确认流程和权限条件。
- 列表中的来源编号改为在“来源说明”中查看，减少重复标签。

## 2026-09-30 顶部工作区折叠

- 八个列表页通过 `ErpWorkspaceHeader` 统一收起筛选、汇总及说明，入口在标题行最右侧的上/下箭头。
- 标题、业务操作、状态标签、批量操作和分页不隐藏；采购的设备/标品切换常驻。
- 筛选区域使用 `v-show`，折叠不清空输入、不触发查询。存在已填筛选项时，标题行保留“筛选 N”入口，点击展开。
- 工作台折叠日期筛选与顶部指标，保留当前周期、图表、财务待办和异常提醒；近期业务表格随剩余高度调整。
- 折叠状态保存在当前浏览器 localStorage，按站点、账号、页面分别记忆，不跨电脑同步。仅保存显示偏好，不保存业务数据。
- 未保存过偏好时，视口高度不超过 800px 或宽度不超过 1100px 默认收起；已有手动选择优先，不随窗口缩放强制切换。浏览器禁用存储时当前页面仍可正常折叠。
- 新页面接入时传入稳定的 `page` 标识，用 `title` / `extra` / `toolbar` 插槽保留常驻内容，默认插槽放可折叠内容。该组件作为 `.erp-list-surface` 的直接子元素，由现有 `ErpDataTable` ResizeObserver 观察实际尺寸变化，不使用固定延时或高度动画。
