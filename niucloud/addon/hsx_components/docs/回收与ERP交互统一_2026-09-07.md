## 2. 修复与体验调整

### 库存排序报错

- 文件：`niucloud/addon/hsx_erp/app/service/admin/ErpStockService.php`，`getPage()`。
- 原因：普通 `order()` 按逗号解析排序字段，把 `IF(a.stock_in_at > 0, a.stock_in_at, a.create_at)` 拆断。
- 修复：固定的内部排序表达式交给 `orderRaw()`，不拼接用户提供的 SQL；相同入库时间继续用资产 ID 稳定排序。
- 验证：普通列表、各周转等级、库存年龄、价格组合查询、分页和站点隔离均有真实数据库断言。

### 搜索与折叠

- 主要业务列表搜索置于标题之后、统计和列表之前。
- 默认“左右”排列：字段名在左，输入框在右；也可选择“上下”。
- 选择保存在当前浏览器的 `hsx.admin.search-layout.v1`，跨已接入页面共用；刷新后仍保留，不写数据库。换浏览器不会同步这个偏好。
- 普通条件直接显示，采购、销售、库存、应收、应付等复杂筛选收进“更多筛选”。
- 折叠使用保留实例的隐藏方式，不清空填写内容，不重建表单。
- 核心列表显示填写条件数量，折叠后仍能知道有条件；提示区分“填写条件”和“点击查询生效”。
- 查询、重置在多数原生查询表单中移到搜索头右侧；简单 Schema 查询仍由 `QueryForm` 管理自身操作区。
- 盘点、代卖两类简单查询复用 `QueryForm` 配置；复杂付款、质检、设备流转继续使用业务表单，未强行抽成统一 JSON。

### 标题、提示与弹层

- 统一 `HsxTitle`、`HsxPage`、`HsxSearchPanel`、`HsxNotice`、`HsxFold`、`HsxDialog`、`HsxDrawer` 和 `useFeedback`。
- 回收既有 `PageHeader`、`PremiumTheme`、`FormDialog` 作为适配层继续复用公共组件，避免逐页维护两套视觉。
- 普通说明默认精简、可展开或关闭；责任归属、财务影响及阻断提醒仍明确保留。
- 成功消息短提示，失败消息延长阅读时间；可手动关闭，重复消息合并。
- 抽屉和弹窗统一尺寸、间距及底部区域；提交中限制重复提交和误关闭。
- 库存档案保留当前成本和关键状态；成本构成、设备流水、账务轨迹按需展开，质检报告可只看需关注项。
- 应收应付紧凑来源信息保留主要单号，次级来源说明通过“来源说明”查看，不删除接口字段。
- 付款账户明确展示“记收支、流水”；编辑、删除图标补充可访问名称，原有说明仍可查看。

### 小可视区域适配

- 按 CSS 可视区域适配，不强制缩小整个网页，也不覆盖用户的系统缩放偏好。

- 搜索自动换行，弹层正文可滚动，底部确认/取消保持可见。
- 修正采购开单的双重高度限制，设备较少时不再强占固定大表格区域。
- 修正回收订单容器高度链，展开高级搜索后不再把表格和分页压到不可操作。
- ERP 看板默认展示净利润、库存、周转、净现金流 4 项核心指标，其余 8 项放入“更多经营指标”，计算口径不变；明确净现金流不等于利润。

### 关键账务预期

1. 补价不是改掉旧流水：已付 4600 保留，调整后总应付 4700，剩余 100 可单独付款。
2. 维修费不能成为无对象的成本：形成维修服务商应付，原设备供应商货款不被混入维修费用。
3. 登记维修费不等于已经付款；实际付款才变更资金账户与结算记录。
4. 申请销售退货不提前回库，确认收到设备后才回库；重复确认不重复执行。
5. 销售退货只对实收部分生成退款应付，未收部分冲销；退款对象、余额和设备成本保持对应。
6. 本轮链路测试在专用隔离站点运行，关闭当前测试进程的外部领域消费者，不发送真实支付、通知或打印任务。
