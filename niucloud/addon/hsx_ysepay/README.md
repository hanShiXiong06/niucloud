# 银盛支付插件（hsx_ysepay）

本插件把银盛 JS 支付和聚合收银台接入牛云统一支付体系。业务插件无需直接依赖银盛 SDK，只需要继续调用牛云现有支付、查单和退款服务。

接口依据：

- JS 支付：https://gateway-doc.ysepay.com/gatewayDocs/summary/N0000384/N0000385/N0000390/I0000253.html
- 聚合收银台：https://gateway-doc.ysepay.com/gatewayDocs/summary/N0000384/N0000483/N0000488/I0000326.html

## 已实现

- 微信公众号、微信小程序 JS 支付原生拉起
- H5、PC、微信公众号、App 聚合收银台跳转
- 微信小程序跳转到小Y聚合收银台
- RSA `SHA256withRSA` 请求签名与响应/通知验签
- RSA PKCS#1 加密随机 AES 密钥
- AES-128-ECB 加密业务报文
- 支付预下单、主动查单、关闭订单
- 原路退款、退款状态查询、退款通知
- 通知商户号和支付金额校验
- 支付与退款通知幂等处理
- 测试环境和正式环境隔离

## 安装

1. 在系统插件管理中安装并启用 `hsx_ysepay`。
2. 进入“设置 -> 支付设置”。
3. 在需要使用的渠道中启用“银盛支付”并打开配置。
4. 填写银盛下发的发起方商户号、收款商户号和业务代码。
5. 上传商户 `PFX/P12` 私钥证书、填写证书密码，再上传银盛平台 `CER/CRT/PEM` 公钥证书。
6. 先使用测试环境完成测试，确认异步通知能从公网访问后再切换正式环境。

插件不新增数据库表，也不要求手工执行 SQL。支付单、退款单仍使用牛云系统原有表。

## 回调

回调地址由牛云支付框架自动生成，不需要手工填写：

```text
/api/pay/notify/{site_id}/{channel}/hsx_ysepay/pay
/api/pay/notify/{site_id}/{channel}/hsx_ysepay/refund
```

线上环境必须满足：

- 使用公网可访问的 HTTPS 域名。
- 网关、WAF 或反向代理不能拦截银盛回调。
- 回调请求体必须原样交给 PHP，不能由代理改写 JSON。
- 服务器时间应通过 NTP 保持准确。

## 微信准备

JS 支付要求用户已经在牛云中取得当前公众号或小程序的 OpenID，并且配置的 AppID 与 OpenID 所属应用一致。

聚合收银台的小程序跳转模式还需要：

1. 在微信公众平台“设置 -> 第三方设置”添加银盛的小Y聚合收银台 AppID。
2. 低于微信基础库 2.23.1 时，把该 AppID 加入 `embeddedAppIdList`。
3. 支付是否成功始终以服务端异步通知或主动查单结果为准，不能只依赖前端返回参数。

## 配置说明

- `运行环境`：测试或正式，两个环境的交易互不相通。
- `支付接入模式`：`JS支付` 用于微信公众号/微信小程序原生支付；`聚合收银台` 用于网页跳转或银盛收银台小程序。
- `发起方商户号`：公共参数 `certId`。
- `收款商户号`：JS 支付对应 `payeeMercId`，聚合收银台对应 `mercId`。
- `业务代码`：必须使用银盛为当前产品和到账方式开通的代码，不能在代码里猜默认值。
- `公众号/小程序 AppID`：仅 JS 支付使用，必须和当前 OpenID 所属应用一致。
- `支付方式`：仅聚合收银台使用，一般按渠道自动选择。
- `JS接口版本`：默认 `1.3`。
- `预下单版本`：默认 `6.3`，对应官方文档最新修订要求。
- `JS支付网关/自定义网关/查单网关`：仅用于银盛为测试商户分配了不同域名的情况。

## 安全

- 后台选择证书后，浏览器只提交 Base64 内容，服务端按支付敏感配置保存。
- 再次打开配置时只返回掩码，不返回证书和密码原文。
- 日志只记录接口名称、站点、错误码和摘要，不记录私钥、AES 密钥、签名或完整报文。
- 对银盛存量旧格式 PFX，插件会在 PHP OpenSSL 3 原生读取失败时调用系统 `openssl -legacy` 兼容解析；服务器若禁用 `proc_open`，请先把证书转换为现代 PFX。
- 不要把测试商户号、证书、证书密码写进代码仓库。

## 上线验收

1. 测试环境分别创建一笔 JS 支付和聚合收银台最低金额订单。
2. 完成支付，确认牛云支付单状态变为已支付且业务订单触发 `PaySuccess`。
3. 重放同一条支付通知，确认仍返回 `success` 且业务不重复执行。
4. 创建未支付订单后取消，确认银盛订单和本地支付单均关闭。
5. 完成一笔部分退款和一笔全额退款，确认退款单最终状态正确。
6. 在启用的微信公众号、微信小程序、H5、App、PC 渠道分别完成实测。
