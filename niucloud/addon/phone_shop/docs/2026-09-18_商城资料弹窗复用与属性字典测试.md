# 商城资料弹窗复用与属性字典

## 结果

“完善并上架”和“完善商城资料”统一使用已有的 `IntakeBuildDialog.vue`。列表只挂载这一个弹窗，不再维护两套弹窗。

- 首次建品：保留分类、价格、配送、交接图片和质检核对，确认后上架。
- 已建品补资料：默认打开“商城属性”，支持保存进度、核对完成和查看处理记录；不显示可编辑的价格、库存或上架操作。
- 容量与颜色使用当前商城分类的规格选项；已选参数模板的同义单选、多选选项也可作为容量或颜色选项来源。
- 成色使用商城已启用的成色等级。
- 商品参数沿用商城现有参数模板，支持单选、多选和模板定义的文本项。
- 电池健康度、保修到期日属于设备实测事实，仍填具体数值或日期。未知显示为空并以原有未知值保存；实测 0% 不误当未知。
- 没有选项时明确提示管理员去商城配置；不临时创建字典项，不编造默认值。
- 交接原值未匹配字典时显示“原值，待对应”，未改动可保留。修改时选择商城标准值。
- 容量/颜色与同义单选模板字段联动，避免筛选信息和详情参数矛盾；后端也校验冲突。

## 业务保护

- 建品和补资料使用不同的原有接口；两种提交函数显式限制模式，补资料不能走建品流程。
- 补资料请求和后端都使用字段白名单，不更新价格、成本、库存、销售状态、财务、ERP 设备关联或商品分类。
- 已售、订单占用、已下架商品补资料后不会重新上架。
- 保留版本校验，其他人员保存后旧版本不能覆盖；刷新选项只更新选项，不覆盖输入、不升级编辑版本。
- 保存失败保留输入并展示原因；保存过程中禁止重复提交和关闭。
- 模板与选项限定本站。参数名称由服务器按选项 ID 生成，拒绝跨站模板、伪造选项、重复字段及错误格式。
- 主站已有代理副本沿用资料传播；参数模板先转换成从站 ID，不直接复制主站模板 ID。不新建商品、不改代理价格和库存。传播失败明确提示主站资料已保存。
