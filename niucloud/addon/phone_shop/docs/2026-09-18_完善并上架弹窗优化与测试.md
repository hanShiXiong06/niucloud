# 完善并上架弹窗：优化与验收

日期：2026-09-18

## 本次解决的问题

原弹窗宽度固定为 720px，所有字段纵向堆放；没有设备图片预览，价格组件被挤在两列小格内，加载或提交异常缺少留在页面上的解释。

新版复用通用组件库的 `HsxDialog`，参照商品编辑页分区。仅调整 `phone_shop` 插件前端，不修改数据库、后端接口、框架或通用组件。

## 操作体验

- 左侧核对设备图片、型号、规格及 IMEI。支持缩略图切换、点击大图；图片来自 ERP 交接，不在这里另建一套图片来源。
- 右侧按“基本信息 / 价格与配送 / 质检与详情”分区。分类、标题优先展示；副标题、标签、服务保障折叠为选填内容。
- 会员定价复用现有 `TierPriceInput`，独占整行；划线价和成本参考默认折叠。
- 分岗模式保留 ERP 价格只读限制，直接核对交接价格，不因打开弹窗触发试算而改写原价。
- 底部操作区固定，明确说明“确认上架后，客户可在商城查看并购买”。缺分类、图片、价格或配送方式时列出缺项，并引导到相应区域。
- 加载失败提供重新加载；提交失败保留当前输入和具体错误；提交期间阻止重复点击和关闭；修改后关闭需要确认。
- 图片预览按 Esc 只关闭大图，不会连带关闭上架表单。
- 支持全屏；适配桌面缩放及 iPad 横、竖屏。成本不在默认首屏显露。

## 保持不变的业务边界

- 沿用原有建品接口、分类选择规则、库存和上架校验，不放宽后端权限。
- 不修改商城已售设备、不自动新增分类、不回填历史数据。
- 不在商城运营弹窗中新增 ERP 图片编辑入口。
- 不静态引入可选的 ERP / 回收插件组件；使用 `phone_shop` 自有质检展示组件。
- 未执行真实商品上架，也未部署生产环境。

## 自动化回归

执行结果：通过。

```sh
node tests/phone_shop_intake_build_ui_smoke.cjs
node tests/erp_mall_frontend_smoke.cjs
node tests/erp_mall_pricing_frontend_smoke.cjs
```

新弹窗检查 Vue 脚本、TypeScript 转译、模板、SCSS 编译和开发/发布镜像一致性。14 组交互覆盖：

1. 图片、分类、价格、基准价正确预填。
2. 分类或配送方式缺失时不调用上架接口，定位对应页签并显示字段错误。
3. 缺图片时明确要求回 ERP 补图、重新交接。
4. 零、负数、非数字、无穷值及未就绪价格规则不能提交。
5. 自动加价复用原接口字段；自动试算不误触发“未保存”提示。
6. 分岗模式保留 ERP 销售价和同行基准价。
7. 提交中不可重复提交或关闭；成功后才刷新列表。
8. 提交失败保留填写内容和具体错误，不误报成功。
9. 加载失败阻止提交，重试后恢复。
10. 快速切换设备时旧响应不覆盖新设备。
11. 关闭后的迟到响应不回填。
12. 分类快速切换时规格选项不串到旧分类。
13. 未保存确认选择继续编辑时保留表单。
14. 图片预览期间不连带关闭上架表单。
