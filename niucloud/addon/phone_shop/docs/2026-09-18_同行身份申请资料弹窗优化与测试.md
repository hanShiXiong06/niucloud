# 同行身份申请资料弹窗优化与测试

## 问题与处理

入口：`site/phone_shop/forward/application` → 查看资料。

原页面将所有表单字段统一转为文字。图片字段虽然已返回图片路径数组，仍显示为地址字符串，管理员无法直接看图。

本次按表单字段类型展示：

- 图片：缩略图、点击放大、同一资料项内多图切换；保留完整签名地址并使用系统图片地址处理方法。
- 普通资料：紧凑的标签/内容布局，选择项显示选项文字，不再显示选项 ID；保留数字 0 和布尔值。
- 申请概况：申请人、身份、状态、审核负责人、时间与审核说明集中展示。
- 使用已有 HsxDrawer，适配窄屏；大图预览按 Esc 不会同时关闭资料抽屉。
- 加载中显示骨架；失败提供明确提示和重试；切换申请清空旧资料，迟到响应不能覆盖新申请。
- 审核通过/拒绝仍使用原有入口、校验、接口和通知流程。

## 浏览器验收

使用 `tests/phone_shop_forward_application_preview.cjs` 加载真实申请页和真实通用抽屉，接口全部使用内存替身，图片使用本地占位图。

- 1280×720：申请信息、图片缩略图、底部固定按钮显示正常，正文独立滚动。
- 768×1024：iPad 竖屏下抽屉、图文行和按钮显示正常。
- 点击第 2 张图片可进入预览；按 Esc 后仍停留在资料抽屉。
- 图片加载失败显示明确文字，不暴露冗长地址。
- 模拟网络失败：显示原因及“重新加载”，重试后正确恢复对应申请。
- 空资料：明确提示核对表单记录，不误报加载成功且有资料。

边界：未登录线上、未读取真实客户申请图片、未执行真实审核或修改会员身份；未验证线上 CDN 权限。浏览器验收结束后已关闭模拟预览服务。
