- 客户点击“我已添加”仅作为流程声明，付款和客户身份继续由群内工作人员核对，避免伪造企微验证状态。

## 2. 本版交付结果

本版在原有项目介绍、群编号、资料采集和审核工单基础上，完成三条新增业务闭环：

1. **一级/二级分销闭环**：项目可选择“所有会员”或“按会员等级”作为推广准入规则，并完成邀请关系、佣金计算、结算、退款冻结与冲红、欠款抵扣、补偿任务、管理台账和会员端查询。
2. **地区参与资格闭环**：管理员勾选允许参与的省、市、区县；客户必须在付款前查询；符合条件后才显示收款码；提交资料时服务端再次校验并保存查询快照。
3. **分销商移动端分享闭环**：系统识别当前会员推广资格；仅已成为分销商的会员显示分享入口；复用框架海报服务生成带签名邀请二维码的项目海报，并支持预览、保存、长按识别和微信分享。

地区功能复用系统现有 `sys_area` 地区数据，没有复制地区表，也没有侵入框架地区模块。插件只为申请工单增加一项 `eligibility_snapshot` 快照字段。

## 3. 地区参与资格产品流程

```text
管理员编辑项目
  ↓
开启“参与地区资格”
  ↓
从系统省 / 市 / 区树中勾选允许参与范围
  ↓
客户打开项目页
  ↓
先选择门店所在省、市、区并查询
  ├─ 不符合：明确提示暂不可参加，不显示收款码
  └─ 符合：显示查询结果和收款码
             ↓
          客户付款、填写群编号及资料
             ↓
          服务端重新校验省市区和允许范围
             ↓
          创建工单并固化地区资格快照
```

### 3.1 管理规则

- 仅配置“允许参与”的地区，不维护禁止名单。
- 省、市、区县采用父子级联勾选：勾选父级会自动勾选全部下级，取消父级也会同步取消下级。
- 勾选省代表该省全部下级地区；勾选市代表该市全部下级区县；勾选区县代表精确范围。
- 同时勾选父级和子级时，保存时自动压缩为最小规则，避免冗余和歧义。
- 已删除或失效的地区 ID 在项目保存时被拦截。
- 单项目最多保存 4000 个有效地区节点。
- 关闭开关后，项目恢复为不限制地区。

### 3.2 客户体验和安全规则

- 地区查询位于收款二维码之前。
- 查询结果显示完整省市区名称和“可以参加/暂不可参加”的明确结论。
- 未通过地区查询时，页面不会显示收款码。
- 客户修改地区后，原查询结果立即失效，必须重新查询。
- 客户端缓存只改善体验，重新进入页面时会静默请求服务端复核。
- 提交和重新提交资料时，核心业务层都会重新校验，不能通过改前端参数绕过。
- 工单保存当时的地区、命中范围、判断结果和查询时间，便于审核和追责。
- 公共项目接口只下发规则是否开启和范围数量，不泄露完整地区白名单。
- 开启规则之前已经办理的历史工单保留原流程，不因缺少快照被误拦截。

## 5. 移动端分销分享海报

### 5.1 用户流程

```text
会员打开项目详情
  ↓
后端按项目选择的推广资格模式判断
  ├─ 所有会员：正常登录会员直接获得推广资格，系数固定 100%
  └─ 按会员等级：读取“项目推广分佣”权益与佣金系数
  ↓
  ├─ 不具备资格：不显示分享海报和推广数据入口
  └─ 已成为分销商：生成短签名邀请凭证
                         ↓
                     点击“分享海报”
                         ↓
                   框架统一海报服务生成图片
                         ↓
              保存图片 / 长按识别 / 分享给好友
                         ↓
              新客户扫码进入项目并绑定邀请关系
```

### 5.2 安全与兼容规则

- 前端只负责展示，后端创建邀请和生成海报时都会重新核验分销资格。
- 海报二维码只携带不可猜测的短签名凭证，不暴露会员 ID、客户群编号或付款信息。
- 短凭证满足微信小程序码 `scene` 长度约束，并包含项目 ID、邀请记录 ID 和 HMAC 签名。
- 伪造或篡改签名会被拒绝；已发出的历史 40 位完整邀请 token 继续兼容。
- 项目关闭分销后，旧海报不能再建立关系；按会员等级模式时，会员等级停用或权益关闭也会立即失效。
- “所有会员”模式不读取会员等级配置，只要求会员属于当前站点、已登录且状态正常，一级和二级系数均固定为 100%。
- 未配置 `eligibility_mode` 的历史项目默认继续使用“按会员等级”，不会因升级自动放开推广资格。
- 项目详情页与“我的推广”页共用框架 `share-poster` 组件和同一套海报数据源。
- H5 可预览海报并复制邀请链接；微信小程序可分享卡片、保存海报及长按识别图片。

## 9. 上线与一键升级步骤

由于当前版本尚未在线升级，本次地区功能已经直接并入同一个 `0.2.0`，不需要再创建 `0.2.1`。

1. 发布完整的 `hsx_project_center 0.2.0` 插件升级包，确保包含 `app/upgrade/v020/Upgrade.php`、海报字典与监听器、后端、管理端和 uni-app 源码。
2. 在线上应用管理执行“一键升级”，建议开启源码和数据库备份以及云编译。
3. 等待升级、菜单刷新和云编译全部完成后，再退出升级页面。
4. 管理员重新登录；如角色看不到分销菜单，重置菜单并重新分配“分销佣金”权限。
5. 进入“项目合作中心 → 项目配置 → 编辑 → 参与地区资格”，开启规则并勾选允许参与的省、市、区县。
6. 用一个允许地区和一个禁止地区分别测试，确认收款码只在允许地区查询成功后出现。
7. 提交一份测试资料，在客户资料审核详情中确认地区名称、查询结论和快照时间。
8. 分别测试“所有会员”和“按会员等级”两种资格模式：前者正常会员均可分享，后者只有开放权益的等级可分享；扫码验证邀请关系绑定。
9. 如实际使用微信小程序，仍需单独重新构建、上传并发布小程序；一键升级的管理端/H5云编译不会自动替代微信小程序提审。
