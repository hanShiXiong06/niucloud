## 四、面单与商城闭环的回归证据

| 业务风险 | 已验证的处理 |
| --- | --- |
| 重复点击、页面重开或更换当前渠道 | 原任务继续复用；按已保存 provider 路由，不重新取号 |
| 取号响应前进程/网络异常 | 发请求前已有持久任务；结果未知保留原申请，查无结果也不释放重下 |
| 已有运单但 PDF 失败 | 先保存运单事实，再请求 PDF；失败为 `print_failed`，不是允许重新下单的 `failed` |
| 模板填错后修正 | 相同账号、相同环境下只采用当前模板并保存回原快照；原运单、密钥和月结不变；不再调用创建订单 |
| 账号/环境发生变化 | 旧任务不借用当前其他账号、环境或模板；保持原凭据快照 |
| `query` 与 `refresh` 混淆 | `query` 只读本地；`refresh` 只查原顺丰订单，不取号、不生成 PDF |
| 返回身份缺失、运单冲突、重复订单提示 | 不凭空成功，不覆盖原运单，保留待核实 |
| 明确参数拒绝与超时 | 仅已确认拒绝允许修正后新尝试；含糊结果保留未知，展示脱敏原因 |
| 取消超时 | 原任务保留，可经原业务守卫重试取消同一原单；明确已取消结果才结束 |
| 取消返回身份冲突或 8019 含糊结果 | 不视为成功取消，不允许另开运单 |
| 取消被网关明确拒绝，例如 A1004 | 恢复取消前状态，保留安全原因；不误报已经取消 |
| PDF 地址/token 泄漏或任意地址代理 | 前端仅获本站任务下载路径；token 加密保存；服务端校验官方域名、HTTPS/443、无跳转、有效期、PDF标识/类型和大小 |
| 跨站下载与PDF对应错误 | 非本站任务拒绝；文件必须匹配原运单；下载不改变为“已打印” |
| 沙箱或失效任务冒充正式发货 | 正式发货服务端拒绝；手填本站已知顺丰单号也校验有效状态、原订单和商品集合 |
