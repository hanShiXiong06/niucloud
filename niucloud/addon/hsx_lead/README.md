# 商户客资协作 · 0.0.1

适用于牛云的商户线索协作应用。商户在手机端发布线索、选择交付门店、接单、反馈结果及付佣；平台在站点管理端配置规则、管理商户、查看协作记录及开展客服抽检。

本目录是 **0.0.1 干净新装源码**，不是旧版增量升级包。不提供旧平台录单、抢单、逐台销售回填、自愿分享台账或历史数据迁移工具。安装及卸载不等于允许清除会员、资金或其他业务数据。

## 核心业务

- 商户使用框架会员身份，同时可以发单和接单，不单独创建商户登录体系。
- 发布需求选择购买、租机或置换，搜索多选型号；不要求录入设备数量。支持图片及聊天截图上传，不读取微信聊天记录。
- 发布者自行选定一家交付门店，先看县区，没有合适门店再扩大到市、省；不是抢单。同范围内靠谱认证优先，其次商户等级和型号交付能力。
- 门店接单后直接与客户沟通、收款，平台不代收购机款、不核算门店利润。门店只需反馈成交或未成交；未成交不收费。
- 成交付佣最低 50 元，管理员可设置更高最低值。平台维护费从实际协作佣金中计算，比例及最低费用必须管理员确认后生效，不对客户货款抽成。
- 真实支付确认后，发布者净收益进入框架会员佣金账户；提现沿用框架页面、规则、审核和打款能力，不另建钱包。
- ERP 为可选能力。没有 ERP 的门店可以在手机端搜索、多选可交付型号后参与匹配；手选型号不是库存，不能据此承诺现货。平台授予全型号交付等级的门店仍按该等级规则推荐。
- ERP 只读采集用于货盘参考，不改价、不扣库存、不锁货、不创建外部订单。门店库存列表只展示当前完整批次里有效的在售有货记录；过期或状态不明的库存不冒充可交付现货。
- 已发布但尚未选店的线索可取消并结束；已交付但对方未接单时可撤回后重新选店。已接单或已成交不能借取消入口跳过付佣。
- 一级推广复用会员 `mid → member.pid`，服务商由管理员开通；发单权益、靠谱认证与平台维护费是否参与及比例分别配置，默认关闭。真实付款核对后形成奖励，等待期到期后记入框架会员佣金账户，不另造钱包或提现流程。
- 已确认的移动原型呈现已落入插件组件：统一搜索与自定义头部、固定交付筛选、级联交付型号、需求数量配置与折叠、本地门店图片及靠谱商家双翼。正式页面不使用原型的合成账户、模拟请求、模拟付佣或模拟提现。

## 入口

平台一级菜单为“客资协作”，二级为工作台、协作线索、合作商户、库存快照、等级认证、客服抽检、协作收款、业务配置、推广管理。可见内容仍受岗位权限限制；普通员工仅查看本人归属的客资及关联业务，商户和库存作为共享匹配资源。

商户移动端通过框架底部导航进入四个页面：

| 页面 | 插件路径 |
| --- | --- |
| 商户交付 | `addon/hsx_lead/pages/workbench/index` |
| 找交付门店 | `addon/hsx_lead/pages/stores/index` |
| 我的收益 | `addon/hsx_lead/pages/wallet/index` |
| 我的门店 | `addon/hsx_lead/pages/profile/index` |

四页均需会员登录，注册来源为 `package/uni-app-pages.php`。H5 地址需加本站框架部署前缀，例如 `/wap/站点ID/`；不要把管理端地址交给商户。

## 安装与首次启用

1. 准备可用的牛云项目环境；管理端使用共享组件库 `hsx_components`，商户移动端使用项目已有的 `uview-plus` 与插件组件，两者不混用。PHP 至少 8.0，需项目原有数据库、缓存、上传和调度能力；凭据加密需要 OpenSSL，中文处理需要 mbstring，机小二身份解析需要 DOM/XML。
2. 将本插件源码放到后端 `addon/hsx_lead`。在框架应用安装及站点套餐中安装、授权本应用；安装表结构以 `sql/install.sql` 为准。不执行已移除的旧升级或开发初始化脚本。
3. 配置并妥善保留 `app.auth_key`，它保护本站 ERP 密码与 Token。密钥丢失或随意更换会导致现有凭据无法解密。
4. 通过框架安装、插件源码同步及页面编译流程生成管理端和会员端集成文件，再正常构建和发布。不要手改共享 `pages.json`，也不要重建已经卸载的旧前端挂载目录。
5. 管理员打开“客资协作 → 业务配置”，确认业务开关、发单价格、付佣与维护费、认证、等级、时限和 ERP 渠道。新装规则和采集计划默认不自动启用，未确认规则不会自动收费。
6. 配置框架收银台、通知及佣金提现，按岗位授予必要权限。商户可先手选交付型号开始使用；如需要 ERP 库存参考，商户本人完成授权并明确开启同步后，再启用框架的“商户ERP库存只读同步”计划任务与项目调度进程。
7. 按 [验收记录](docs/TEST_REPORT.md) 完成一次真实业务验收。编译成功不等于支付、通知送达、ERP 同步或提现实际打款成功。

## ERP 登录与采集

万机管家、搜机客、机小二支持保存授权账号密码后正常自动续登；爱管机按图片验证码正常登录，会话失效需重新验证，不承诺仅凭密码无人值守续登。所有自动续登都必须校验原来源门店，不能把其他店的数据接进来。

ERP 渠道由每个站点管理员分别开启或关闭。关闭后同时暂停该渠道已有连接的授权和采集，保留密码密文、历史库存及商户原同步开关；重新开启不会替商户打开其自行关闭的同步。

验证码识别是可选的本站付费服务，仅向识别服务发送验证码图片，不发送 ERP 密码。没有启用识别时仍可手动验证；短信、滑块、风控或额外验证必须正常处理，不能绕过。详细说明见 [ERP 接入与自动同步](docs/ERP_INTEGRATION.md)。

## 源码与发行边界

2026-11-04 接真实推广时新增 **1 张 `hsx_lead_promotion_reward` 奖励记录表**，无已有表字段变更。已加入两份一致的安装 SQL；覆盖代码不等于已建表。已有测试安装须先通过安装/升级入口执行 SQL，或按真实前缀执行新增表的 `CREATE TABLE IF NOT EXISTS` 段。无需清库、不补算旧单，退款后的已入账奖励明确转人工核对，不冒称自动追回。详见下方推广说明。

- `app/`：后端业务、适配器、通知、菜单及事件。
- `admin/`、`uni-app/`：本插件前端安装源，不依赖已卸载的 `admin/src/addon/hsx_lead`、`uni-app/src/addon/hsx_lead` 挂载目录。
- 移动端布局由实际使用它的组件本地 `scoped` 样式负责，共用规则以 Sass 按需复用；不依赖父组件 `:deep` 穿透微信小程序隔离，不向公共组件库或框架全局注入样式。命名插槽的内容样式也保留在调用方。
- `package/`、`resource/`：框架页面注册与预置导航资源。
- `sql/` 与根目录 SQL：本版本安装、卸载入口；不包含跨版本迁移。
- `tests/`：开发回归，不进入源码安装包。
- `scripts/package.mjs`：白名单源码打包及 SHA-256 清单，不安装插件、不连接数据库、不访问 ERP、不编译前端。
- 图标生成脚本只供开发维护，安装包已含生成的 PNG，正常安装由框架发布资源，不依赖开发脚本运行。

开发人员在项目根目录执行 `node niucloud/addon/hsx_lead/scripts/package.mjs` 可生成 `output/` 下的 0.0.1 源码安装包、manifest 与校验和。包内保留 `niucloud/addon/hsx_lead/` 相对路径，解压后将该目录放入目标项目对应位置；不含框架源码、数据库数据、账号凭据、依赖库、历史升级工具或编译成品。
