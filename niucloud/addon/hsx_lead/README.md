# 商户客资协作 · 0.0.1

面向牛云的商户线索协作应用。商户在手机端发布客户需求、选择交付门店、接单、反馈成交结果及付佣；平台负责业务配置、监管、抽检及财务核对。客户货款由客户直接与门店结算，平台不代收购机款、不核算门店利润。

本目录是完整插件源码，不是编译成品。当前已有正式付费用户：覆盖更新须保留业务、支付、权益和分佣记录，不卸载重装、不运行测试数据清理。早前测试阶段已退役重复的普通入驻、靠谱认证、S/A/B及固定四档会员实现；本轮不再清理或补算历史数据。

## 当前会员方案

只有两条独立身份：

- 门店主体会员：默认普通会员，付费等级由牛云“会员 → 会员等级”创建。开启其中的“商户主体权益”，配置人数、协作权限和购买周期。支持5、6、8等数量的等级，不固定四档；仍受框架自身会员等级数量限制。
- 服务商：个人推广身份，免费申请、平台人工审核；普通邀请人与服务商按后台分别配置的比例获佣。购买门店会员不会自动成为服务商。

主体共享等级、有效期与账号名额；人数包含负责人。购买主体权益不修改个人 `member.member_level`，不自动发放框架个人成长礼包。后台“业务配置”只读展示会员目录，不再保存另一套会员价格。

门店经验与个人成长值分开：承接门店实际支付的协作佣金按1元1点派生，成功退款扣回；等级可独立开启“付费补足经验”，只补目标等级缺口，单价由后台配置。真实付佣经验、购买经验分别展示，购买经验不增加真实成交次数。开通、升级和续费均按实时经验核验，由商户自愿付费，不自动扣费或晋级。管理员须明确指定唯一启用的“入门等级”，这一档免经验门槛；其他档门槛直接在原会员等级编辑页顶部“成长值”调整，不另存一套配置。

会员付款分为可退押金、周期服务费、可选补足经验费，一次使用框架收银台支付。升级只补押金差额，续费不重复收押金；邀请分佣只按实收服务费计算，押金和经验费不参与。商户可从会员页申请退出退押金，在“押金退还”后台审核；未完结协作和待付款先处理，退款按原支付来源核对，不把审核通过当成到账。配置与分项事实均复用已有JSON，本次不新增表、字段或框架业务分支。

会员等级外观在同一个权益钩子内配置：自动与六种配色预设、自定义渐变、卡面上传、头像标识效果。主动应用配色才生效，图片、角度与效果开关可独立调整；外观不会改变会员权限或支付规则。

购买周期默认全部关闭；可分别开启月付、季付、年付，也可添加1—120个月的自定义周期。开启后必须设置大于零的价格，未开启不向商户显示价格或购买入口。

详见 [主体会员配置与业务边界](docs/ENTITY_MEMBERSHIP_20261106.md) 和 [本轮验收记录](docs/ENTITY_MEMBERSHIP_TEST_20261106.md)。

## 核心业务

1. 商户使用框架 member 登录，创建门店或以主体码申请加入已有门店；负责人确认后才能访问门店业务。
2. 登记联系人、地区、门头照片、营业执照及经营能力。ERP授权是可选项，也可手选型号、品牌或运营商；手选能力不是现货承诺。
3. 发布者按业务填写需求，通过客户所在县区查找交付门店，必要时扩大到市、省；不是抢单。先匹配地区和业务能力，再按有效主体会员等级等客观维度排序。
4. 承接门店自行联系客户，只需反馈成交或未成交。未成交不收协作费用；成交最低付佣与平台维护费由后台按业务配置并冻结到该线索。
5. 确认真实支付后，发布方净收益记入框架会员佣金账户；提现沿用框架账户、申请、审核与打款页面，不另造钱包。
6. 一级推广以 `mid → member.pid` 归因；当前计佣来源为“主体会员服务费”和“平台维护费”。免费普通用户、各动态会员等级、服务商可分别配置比例，服务商独立优先、不叠加；押金与经验费用不分佣。详见 [本轮操作与验证](docs/COOPERATION_ADMIN_RECOVERY_20261108.md)。
7. 未选店线索可取消；未接单交付可直接重新选店或单独撤回。先确认新门店才原子替换，取消选择不丢原分配。到期或退款不把历史履约、原账款处理入口藏进会员付费门槛。

首页与个人中心接入牛云自定义装修；找门店和找客户保留独立角色页，共用搜索、列表和任务组件。发布、选店、详情、ERP、付佣、成员与会员使用真实页面栈，不靠旧套餐遮罩替代导航。

装修沿用牛云通用区块、图文导航与背景样式；蓝白首页分为标题区、找门店卡片、找客户卡片、业务快捷入口四块，分别调整背景、背景图、插画、按钮色与位置。组合入口仍可选，两张卡在组合内部也可分别设置；原素材保留，底部重复工具默认隐藏。组合区块的四种布局预设需确认应用，不自动覆盖自定义配色。首页装修提供“备份后应用蓝白预设”，使用框架复制、读取、保存能力，确认原JSON备份后才替换当前首页，再回读核对；不新增API或表。字典默认值不会自动重写已保存页面。详见 [装修配置与渲染边界](docs/DIY_APPEARANCE_20261106.md)。

### 仅本机全测试环境：清理退休测试权益

`clean-retired-membership.php`不是正常升级、生产迁移或退款工具。它会检查所有站点的退休测试套餐、关联流水与旧字段，可能删除这些测试事实，并还原可严格核实的纯测试余额扣款。只允许本机MySQL；远程库、真实外部收退款、已入账推广奖励或不一致账本会阻止执行。

```sh
php addon/hsx_lead/scripts/clean-retired-membership.php --check
# 只有确认该插件所有站点数据均为测试，且核对预检、完成完整备份后：

```

备份保存在PHP项目 `runtime/hsx_lead_upgrade/retired-membership-*`。此命令不会向微信/支付宝发起真实退款，也不能用于清理正式资金记录。

## 首次配置

1. 通过牛云应用安装、站点套餐授权并完成源码与资源集成。PHP至少8.0，使用项目既有MySQL、缓存、上传和调度能力；保留原 `app.auth_key`。
2. 在框架会员等级编辑器启用“商户主体权益”，设置等级名称与不同的正整数成长值（排序及非入门档升级门槛）、账号人数、权限及可购买周期。明确勾选一个“入门等级”免经验门槛，按需选择等级颜色；查看业务配置中的只读标识和门槛确认结果。
3. 在业务配置核对业务、需求目录、补充字段、最低付佣、平台维护费与跟进时限，明确确认后启用。服务商推广规则单独设置。
4. 配置框架支付、通知、佣金提现及岗位权限。ERP由商户主动授权并开启同步；调度任务与通知模板分别检查，保存配置不代表已经执行。
5. 从入驻、购买、发单、选店、接单、成交付佣到收益核对，按本轮验收文档重新走通。编译成功不等于支付到账、通知送达、ERP采集或实际提现。

## ERP与素材边界

万机管家、搜机客、机小二使用已授权账号正常登录与续登；爱管机可能需图片验证码。短信、滑块、风控等必须正常验证，不能绕过。渠道关闭会暂停其已有连接的自动同步，不改外部库存。

采集只读参考库存，不向外部ERP改价、扣库、锁货或下单。库存只展示完整发布批次中确认有效的在售有货记录；过期、来源状态不明不当成可卖现货。详见 [ERP接入](docs/ERP_INTEGRATION.md)。

门头是公开展示资料，营业执照私密保存与授权查看；聊天截图由用户主动上传，不读取微信聊天记录。图标、等级效果与海报素材不能冒充真实门店或商品实拍。
