# 首次配置与通知

适用：`hsx_lead 0.0.1` 新装。安装包不带商户账号、测试业务数据或收费服务密钥；也不自动开启业务、计划采集、付费识别或消息群发。

## 1. 按顺序配置

| 谁配置 | 在哪里 | 需要准备什么及确认什么 |
| --- | --- | --- |
| 部署人员 | 框架安装、编译与发布流程 | 当前插件源码、共享组件库、四页注册和预置资源；PHP、数据库、缓存、上传、调度可用 |
| 部署人员 | 项目环境配置 | 安全固定的 `app.auth_key`；对 ERP 固定 HTTPS 服务的正常网络访问，不关闭 TLS 校验 |
| 站点管理员 | 客资协作 → 业务配置 | 业务开关、是否付费发单及月价、最低付佣、维护费比例及最低费用，核对示例后确认收费规则 |
| 站点管理员 | 业务配置 → ERP 登录渠道 | 选择本站实际使用渠道；关闭会暂停已有连接的采集 |
| 站点管理员 | 业务配置、等级认证 | 等级库存门槛、排序、是否授权最高等级全型号；认证价格及期限、人工核验人员 |
| 站点管理员 | 框架支付设置 | 本站合法可用的支付渠道，不能以生成付款单代替真实收款 |
| 站点管理员 | 框架佣金提现设置 | 开关、最低额、手续费、账户和审核方式；插件不重复维护一套 |
| 权限管理员 | 框架角色与权限 | 页面读取、操作、本人/全站范围、转交、抽检、规则和财务权限；普通岗位不默认给超级管理员 |
| 商户 | 手机端 → 我的门店 | 真实门店、联系资料、地区、ERP 账号并明确授权同步 |
| 运维 | 牛云计划任务及项目调度进程 | 确认商户连接已启用，开启“商户ERP库存只读同步”，查看执行日志 |

保存业务规则只保存配置，不会付款、转账或自动代商户登录。管理员人工授予权益、认证或停止合作时应保留理由和操作人。

## 2. 佣金与提现仍用框架

协作收款是付佣、发单权益和认证的业务付款单。发布者佣金总账、提现申请、审核和转账走框架本身的菜单及权限：

- 配置：`/site/setting/cash_out`。
- 佣金总账：`/site/member/commission`。
- 提现审核与打款：`/site/finance/cash_out`。

有插件收款单权限不等于有框架提现打款权限。实际购机款由客户直接付给承接门店，不通过这些协作收款单。

## 3. 配置商户通知

入口：“客资协作 → 业务配置 → 通知渠道”。使用牛云通知模板、渠道服务和日志，两个场景为“商户新工单提醒”“商户工单处理结果提醒”。

| 渠道 | 配置顺序 | 接收前提 |
| --- | --- | --- |
| 小程序 | 核对本站官方公共模板及关键词，在插件登记映射，再到 `/site/channel/weapp/message` 获取并开启模板 | 同站点会员绑定小程序身份，并主动同意订阅；不能强制订阅 |
| 公众号 | 核对本站公众号模板及字段，登记映射，再到 `/site/channel/wechat/message` 获取并开启 | 会员绑定本站公众号身份，公众号权限及模板规则允许发送 |
| 短信 | 在 `/site/setting/notice/template` 配置已审核短信模板并开启，另核对短信账号、签名和余额 | 会员有有效手机号，服务已开通且可能按次计费 |

模板编号与字段须来自本站有权限的官方后台，不从别的站点抄一个 ID，也不编造模板。变更映射后原框架模板会停用，需要重新获取、核对并开启，避免字段错配。

公众号还需要配置可访问的公网 HTTPS 会员端入口；小程序通知落到已发布的商户交付页，并携带协作编号。发通知只含工单号、状态和提示，不在通知中暴露客户完整电话、附件或 ERP 凭据。

当前企业微信通道面向员工 `uid`，商户是会员 `member_id`，未建立合法身份绑定时不把会员强当员工发送。本版本不新增站内信系统，也不把“安装了企微插件”写成商户企微通知已打通。

## 4. 看懂通知结果

- 未配置或关闭：本次未向该渠道提交，先补模板、开关或账号。
- 接收身份缺失：商户完成对应渠道登录或绑定；小程序还要主动订阅。
- 已提交：只表示已交给框架通道，不证明终端已收到。
- 结果待核实：可能已经提交，先查框架通知或短信记录，不盲目重发。

框架通知记录入口 `/site/setting/notice/records`，短信记录 `/site/setting/sms/records`；同时核对协作详情的本业务通知状态。工单保存和处理不依赖消息送达，商户始终可以主动打开商户交付页查看自己的待办。

## 5. 配置与采集故障

| 提示或现象 | 先检查 |
| --- | --- |
| ERP 凭据无法解密 | 原部署密钥是否保留；不要随意更换 `app.auth_key` |
| 渠道关闭，采集暂停 | 本站渠道开关，不要反复重新授权 |
| 已连接但没有自动任务 | 商户同步开关及到期时间、框架计划开关、调度进程及日志 |
| 授权或验证码过期 | 商户在手机端正常重新验证，不能让后台无限重试 |
| 收银台已付但权益待核对 | 查原业务单和框架支付事实，特别核对门店是否停止合作 |
| 新菜单或手机页面不存在 | 确认按框架完成安装、套餐授权、菜单/页面集成和前端发布，而不是只复制源码 |
