# 线索交付与可选 ERP 使用说明

业务核心是“发布线索 → 选定交付门店 → 门店承接 → 反馈成交或未成交”。ERP 是可选的货盘参考能力，不是发单、接单的前置条件。

## 商户如何开始

1. 使用本站会员登录，登记门店名称、联系人、电话和门店地址。
2. 没有 ERP：选择暂不接入，搜索、多选自己能交付的品牌型号，保存。门店可以正常发单，也会进入对应型号的交付门店推荐。
3. 有 ERP：也可以先手选型号使用，之后再授权 ERP 并开启库存同步。两种依据可以并存；手选型号只表示门店声明的交付能力，不代表台数、价格或现货。
4. 发单权益、靠谱认证、商户等级仍按本站配置生效。选择“无 ERP”不会绕过权益付款、黑名单或会员权限。

门店地址用于展示与被推荐；发布线索中的“客户地区”用于寻找交付门店，两者不是一个地址。手机号和完整客资仍只向有权处理该线索的人展示。

## 发布、取消与选店

- 发布后未选门店：可以继续选店，也可以点击“取消线索”结束；取消后不能再次交付该条线索，不产生单次付佣账目。
- 已交付、对方未接单：点击“撤回交付”退回待选门店，再重新选择。撤回不等于取消整条线索。
- 对方已接单：不能再通过未选店取消入口关闭，需要按实际结果回填；成交后沿用既有付佣流程。
- 关键动作均由服务端核对当前归属、状态和交付版本；重复点击不能重复取消、重复交付或绕过账务。

从线索进入选店时，系统默认按该客户的区县查找；没有合适门店再查全市，仍没有再查全省，不需要商户另选“优先本区县”。系统不会拿发布商户自己的门店地址覆盖客户地址。

从“找交付门店”独立查询时，可以只选省、选到城市或选到区县后查询；不要求补齐三级。列表会说明当前结果范围，无结果和加载失败分别提示。

手选可交付型号、有效 ERP 库存以及平台配置的全型号交付等级，均可作为匹配依据；推荐仍保留靠谱认证和等级排序。手选型号数量不会加入库存数量，也不会用于伪造库存等级。

## 门店货盘怎么查看

门店卡上的库存/货盘入口可打开只读列表，支持搜索与分页。ERP 列表仅展示同一站点、该门店当前完整同步批次里新鲜的在售有货记录，并显示快照时间。

未接入 ERP、暂停同步、还未完成首次同步或没有有效在售快照时，显示对应原因，不用假库存填充空列表。手选能力与 ERP 快照分开展示。库存接口不向同行返回 IMEI、成本、采购价、授权信息、客户资料或原始 ERP 响应。

价格、库存和交付时间仍应由双方在承接前核对；参考列表不锁货，不保证机器仍在店，也不意味着平台代收客户购机款。

## 全量同步与进度

“开始同步”创建一次完整库存任务，服务端每次有界读取一页，直到来源分页结束才发布整批库存。比如来源有 205 条，读取第一批 100 条时仍是进行中；读完 3 页共 205 条才显示完整同步完成。

面板打开时持续读取真实进度；主动同步会分步推进，不需要反复点一次读一页。面板关闭后若尚未完成，自动继续仍依赖已启用的牛云计划任务和项目调度进程；不要把关闭面板当作已完成。

后台完成后，重新读取连接状态会使用同站、同连接的任务事实，不继续显示页面缓存中的“采集中”。失败、暂停和中断保留各自状态；半批库存不会覆盖上一批完整快照。

## 通知怎么配置

不另建短信、公众号或小程序发送系统：业务事件经插件 `HsxLeadCollaborationChanged`，通过牛云 `NoticeData` 钩子和官方渠道发送服务处理。

管理员从“客资协作 → 业务配置 → 通知渠道”核对两个现有场景：商户新工单提醒、商户工单处理结果提醒。

- 小程序：在本站小程序订阅消息渠道获取并开启已核验模板；商户需在微信小程序内主动点击订阅。
- 公众号：在本站公众号模板消息渠道获取并开启模板；接收会员须绑定本站公众号身份，跳转需配置公网 HTTPS 入口。
- 短信：沿用牛云通知模板、短信账号、签名和审核模板；必须有有效手机号及可用余额，发送可能计费。

三渠道分别记录结果。未配置、会员未绑定、未订阅、渠道异常均不能显示为“已送达”。工单详情的通知记录和牛云通知/短信日志用于核对；通知失败不回滚已经保存的交付或成交结果，也不自动盲重发。

企业微信仍是不同身份通道，本轮不把会员 member_id 当作员工 uid 直接发送。未新增表、字段或框架文件，不需要执行数据库升级 SQL。

## 已安装站点如何应用本次修复

版本仍为 0.0.1，不需要卸载、清库或执行 SQL。先备份再覆盖后端插件；已安装项目还需将插件内 `admin/` 和 `uni-app/` 安装源同步到各自前端的 `src/addon/hsx_lead/`，再按正常流程打包、发布管理端与小程序/H5。只覆盖后端不会改变已经打包发布的手机界面。

本次验收目录 `output/hsx-lead-acceptance-20261103/mobile-build/` 使用合成账户和网络替身，不能当作生产前端发布；生产环境必须使用真实项目的构建配置、域名和会员登录。

### 手机界面样式修复

这次修复的是插件移动组件的样式归属，不需要更新 `hsx_components`、`uview-plus`、框架或数据库。发布线索、付佣、门店资料、收益、详情和 ERP 连接的布局由各自组件本地加载，不再依赖工作台父组件向下穿透；共用规则仍在插件内按需复用。

已安装项目需完整同步插件 `uni-app/` 安装源，包括本次新增的 SCSS 文件，再重新编译并发布实际使用的微信小程序或 H5。不要只替换 `CooperationWorkbench.vue` 或只上传后端；样式并非由后端接口返回，也不会因清理 PHP 缓存而更新。生产发布后应确认打开的是新版本，检查发布表单、门店资料、交付详情底部按钮和收益页。
