# 商户与平台操作手册

适用：`hsx_lead 0.0.1`。客户直接与门店成交、向门店付款；平台提供线索协作、收取协作维护费，不代收客户货款、不核算门店利润。

## 1. 谁负责什么

| 角色 | 主要工作 | 不应代替的动作 |
| --- | --- | --- |
| 发布商户 | 登记需求及联系授权、选择交付门店、查看结果 | 不向多店同时抢派同一客户 |
| 承接商户 | 接受或拒绝、联系客户、反馈成交或未成交、成交付佣 | 不把接单视为已经成交 |
| 平台运营 | 管理规则、等级和认证，查看归属、转交内部跟进责任 | 不替客户支付货款，不以统计自动判定飞单 |
| 客服 | 联系客户抽检，记录反馈、证据和结论 | 不因多次未成交直接拉黑 |
| 财务 | 核对真实支付，按框架规则审核提现并完成实际打款 | 不把点击确认当成银行已转账 |

## 2. 商户入驻

1. 商户使用本站会员登录“我的门店”，填写店铺、联系人、电话、省市区、地址及 ERP 渠道。平台代录资料时也应绑定门店实际使用的会员。
2. 商户本人填写授权账号密码、完成正常验证，核对来源门店，点击接入并开启自动同步。
3. 查看首次采集任务和最终发布结果。已登录不等于已采集；失败或过期快照不能冒充最新库存。
4. 按需购买发单权益或靠谱认证。认证付费后仍需平台核验；靠谱标识不等于平台保证现货、成交或赔付。
5. 靠谱认证可以永久有效，也可设置期限。平台仍可撤销认证或停止合作。商户等级与靠谱认证分别维护，不能把设备成色当成商户等级。

## 3. 发布线索与选店

1. 在手机端商户交付页发布线索，选择购买、租机或置换。
2. 搜索并多选需求型号，只需型号，不要求台数。可上传图片或聊天截图；系统不会自动读取微信聊天。
3. 填写必要客户联系资料及地区，确认已经取得联系授权。
4. 如果本站要求付费发单，先在框架收银台购买权益。有效期从实际确认付款起算一个月，不是到自然月月底；再次购买和期限以付款单及服务端结果为准。
5. 从候选列表选择一家门店：先县区，再按需扩大到市、省。同范围内先看有效靠谱认证，再看等级、型号交付能力。自己、停用、拉黑及无交付能力的门店不参与。
6. 最高等级可由平台明确授予全型号交付能力，但不代表实物现货或跨系统锁货，接单前仍须门店确认。

## 4. 接单与回填

承接商户在手机端查看待接线索，只需接受或拒绝。接单前客户完整电话和附件隐藏；接受后再解锁联系资料。

- 对方拒绝：线索回到待选店，发布者可重新选择。
- 尚未接受：发布者可以撤回后重新选店。
- 已接受：承接商户直接联系客户，沟通成交，不经过平台收货款。
- 跟进结束：选择“已成交”或“未成交”。未成交不收费，不要求填写购机款或利润。
- 页面提示记录已变更：重新读取，不沿用旧分配版本操作，不同时向多个门店重复派单。

平台设置的接单、联系、回填时限用于提醒与抽检，不自动认定飞单、不自动扣款或停止合作。

## 5. 成交付佣

成交后填写协作佣金，系统最低 50 元；若本站配置更高最低值，以页面提示为准。没有另设业务最高限额，但仍受收银台和金额字段精度限制。

创建付款单时展示总佣金、平台维护费、发布者净收益。平台维护费针对本笔协作佣金，不针对客户货款或利润；规则取服务端付款单快照，已创建的支付单不会随后台改规则而悄悄改价。

例如管理员确认“维护费 10%，最低 9.9 元”：付佣 50 元，维护费 9.9 元，发布者净收益 40.1 元。该数字只是示例，不代替本站正式配置。

通过框架收银台付款后，重新读取真实结果。关闭弹窗、收到客户端成功提示、创建了付款单都不等于到账；网络不确定时先查原单，不按另一金额重复创建付款。重复成功回调不能重复增加佣金。

## 6. 收益与提现

真实付款确认后，净收益进入发布者的框架会员 `commission` 账户。本插件只提供本插件的收益来源明细，不另建提现申请、审核、冻结或打款流程。

| 使用者 | 框架入口 |
| --- | --- |
| 商户查看佣金总账 | `/app/pages/member/commission` |
| 商户申请提现 | `/app/pages/member/apply_cash_out` |
| 商户查看提现记录 | `/app/pages/member/cash_out` |
| 平台查看佣金总账 | `/site/member/commission` |
| 财务审核与打款 | `/site/finance/cash_out` |
| 管理员设置提现规则 | `/site/setting/cash_out` |

插件移动端跳转提现前会指定 `cashOutAccountType=commission`。会员佣金账户可能含其他插件收入，余额、累计佣金及提现属于同一共享账户；只有协作收益明细是本插件来源，不能要求其合计必须等于全部账户余额。

提现开关、最低额、手续费、账户、审核和实际转账由框架配置。维护费不等于提现手续费。人工打款必须先核对账户并实际转账，再按框架确认、留凭证；不得把系统按钮当成真实到账。

## 7. 平台监督

管理员在协作线索中检索时间、参与人、状态和归属，查看操作历史。普通员工仅看本人归属客资及关联业务；管理员按权限查看全量并转交内部跟进责任。转交不改变承接门店、不重派客户、不改付款金额、不发送重复通知。

抽检应记录客户反馈及证据。确认成交却故意反馈未成交等违规，需要人工复核、填写原因并二次确认后永久停止合作；历史及合法佣金保留，平台不垫付逃单佣金。系统按同站点会员和登记电话阻止重新入驻，不承诺识别所有换号主体。

## 8. 常见问题

| 现象 | 下一步 |
| --- | --- |
| 没有合适门店 | 扩大地区，核对门店资料、渠道开关、完整同步及交付能力 |
| 接入成功但库存为空 | 查看任务是否真正完成，以及上游是否确有符合范围的在售设备 |
| 未看到通知 | 主动打开商户交付页；通知不代替工单保存，另核对身份绑定、模板和发送记录 |
| 权益已付款未生效 | 查原收款单及人工核对提示，不重复付款，不自行解除停用 |
| 提现入口不可用 | 查框架提现开关、规则、账户和权限，不在插件另记已打款 |
