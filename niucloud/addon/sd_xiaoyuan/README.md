# 校园帮 (sd_xiaoyuan)

校园跑腿服务系统，集校园认证、代取快递、跑腿代买、接单员接单、收益提现等功能于一体。

## 功能特点

### 用户端功能

#### 1. 校园认证
- 支持学生、教师、教职工身份认证
- 上传证件照片审核
- 确保校园内用户安全使用

#### 2. 多种服务类型
- **代取快递**: 自动同步快递信息，支持取件码加密
- **代买服务**: 代买餐饮、零食、文具等
- **跑腿服务**: 代打印、代排队、代占座等
- **预约下单**: 支持预约未来时间配送
- **加急服务**: 支付额外费用优先配送

#### 3. 地址管理
- 保存常用地址（宿舍、教学楼、快递点）
- 支持一键选择常用地址
- 分类管理不同类型地址

#### 4. 优惠系统
- 满减券、折扣券
- 月卡会员免配送费
- 新人优惠券

#### 5. 订单追踪
- 实时查看跑腿员位置
- 订单状态实时更新
- 在线沟通功能

#### 6. 评价系统
- 多维度评分（服务、速度）
- 文字评价和图片评价
- 支持匿名评价

### 接单员端功能

#### 1. 身份审核
- 提交学生证认证
- 管理员人工审核
- 审核通过后可接单

#### 2. 订单管理
- 订单大厅抢单模式
- 智能推荐附近订单
- 实时查看订单详情

#### 3. 任务执行
- 实时位置更新
- 订单状态流转
- 取件凭证上传

#### 4. 收益管理
- 查看订单收益明细
- 平台抽成透明化
- 支持多种提现方式（微信、支付宝、银行卡）

#### 5. 等级系统
- 高评分获优先推荐标签
- 可接高佣金订单
- 信誉等级提升

#### 6. 接单限制
- 设置每日接单上限
- 防止超负荷接单
- 保障服务质量

#### 7. 异常申诉
- 对恶意差评申诉
- 对恶意取消订单申诉
- 管理员仲裁机制

### 管理后台功能

- 校园认证审核
- 接单员入驻审核
- 订单管理
- 提现审核
- 数据统计
- 平台配置

## 数据库设计

### 核心数据表
1. `xiaoyuan_campus_auth` - 校园认证表
2. `xiaoyuan_runner` - 跑腿员表
3. `xiaoyuan_order` - 订单表
4. `xiaoyuan_order_log` - 订单日志表
5. `xiaoyuan_evaluate` - 评价表
6. `xiaoyuan_address` - 地址表
7. `xiaoyuan_coupon` - 优惠券表
8. `xiaoyuan_coupon_record` - 优惠券领取记录
9. `xiaoyuan_vip` - VIP会员表
10. `xiaoyuan_runner_balance_log` - 跑腿员余额日志
11. `xiaoyuan_withdraw` - 提现记录表
12. `xiaoyuan_appeal` - 申诉表
13. `xiaoyuan_config` - 配置表

## 费用计算规则

### 基础费用
- 起步价: 3元
- 距离费: 超过2公里，每公里1.5元
- 重量费: 超过5公斤，每公斤0.5元
- 加急费: 5元

### 抽成规则
- 平台抽成: 20%
- 跑腿员收益: 80%

## 安装说明

1. 将插件复制到 `niucloud/addon/` 目录
2. 在管理后台安装插件
3. 配置相关参数
4. 部署Uniapp前端

## 使用说明

### 用户端
1. 完成校园认证
2. 选择服务类型
3. 填写订单信息
4. 提交订单并支付
5. 等待接单员接单
6. 订单完成后评价

### 接单员端
1. 申请成为跑腿员
2. 等待审核通过
3. 上线接单
4. 在订单大厅抢单
5. 按流程完成订单
6. 查看收益并提现

## 注意事项

1. site_id在业务层获取，不在控制器层
2. 所有金额使用decimal(10,2)存储
3. 时间统一使用int类型存储时间戳
4. 状态使用tinyint或enum类型
5. 经纬度使用varchar(50)存储
