# 企业微信通知接入与上线

## 最终使用入口

本插件默认使用企业微信服务商标准第三方应用，客户不再手工填写 `CorpID` 和 `Secret`。

- 平台端一次性入口：`系统设置 / 企业微信服务商`
- 客户站点入口：`企业微信 / 协同配置`，路由为 `/site/hsx_wecom/config`

客户站点的实际流程只有三步：

1. 站点管理员点击“一键授权企业微信”。
2. 员工在企业微信内打开绑定链接，将系统员工与企业微信成员身份绑定。
3. 点击“发送测试通知”，员工收到消息后点击卡片，进入当前 SaaS 的后台管理小程序。

## 平台第一次配置

1. 安装或升级 `hsx_wecom`，插件安装/升级会幂等创建服务商、客户授权、回调事件、员工绑定和消息日志表。
2. 重置插件菜单，进入“系统设置 / 企业微信服务商”。
3. 填写服务商 CorpID、SuiteID、SuiteSecret、回调 Token 和 EncodingAESKey。
4. 填写这套 SaaS 对应的后台管理小程序 AppID、小程序名称和 SaaS 根域名。
5. 保存后，系统会生成两个准确地址：
   - 事件回调 URL：配置到企业微信服务商应用的数据回调中。
   - 授权回调 URL：配置到第三方应用的授权完成回调中。
6. 企业微信推送 SuiteTicket 后，返回系统点击“验证服务商通道”。

两套同源 SaaS 分别在自己的平台端配置本部署的通道标识、域名和后台管理小程序 AppID。消息发送前会同时校验站点、Suite、授权企业、AgentId 和管理小程序 AppID，防止两套 SaaS 串线。

## 上线前必须确认

- 后台管理小程序已与当前企业微信第三方应用完成关联。
- 第三方应用的可见范围包含需要收信的员工。
- 回调域名使用 HTTPS，且已在企业微信平台配置为可信域名。
- 如使用企业微信付费接口许可，当前授权企业的账号数量与有效期满足发消息要求。
- 在“接收员工”中完成员工授权绑定，不要将其他企业的 UserID 手工填入当前站点。

## 兼容旧的自建应用

已经在生产环境使用的自建应用不会被删除。站点可在“高级兼容模式”继续使用原 CorpID、AgentId 和 Secret；新客户默认使用一键授权。

## 通知可观测性

- 每条通知都会记录站点、授权企业、通道、AgentId、接收员工、目标页面、企业微信响应和失败原因。
- 失败消息最多自动重试 5 次，也可在消息日志中手动重试。
- 企业取消授权后会立即停止投递，防止把其他站点的消息发到错误企业。
- “发送测试通知”是上线验收入口：只有真正收到卡片且能打开当前后台管理小程序，才算接入完成。
