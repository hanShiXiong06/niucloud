# Recycle 插件架构重构与第三方服务整合方案

## 文档概述

**项目：** NiuCloud Recycle 回收插件
**日期：** 2026-02-03
**目标：** 重构目录结构、修复订单流程Bug、设计统一的第三方服务管理架构

---

## 一、问题起因

### 1.1 Model 层目录混乱

**问题描述：**
- `/addon/recycle/app/model/` 目录下有17个模型文件堆在根目录
- 存在重复文件：`RecycleDeviceBrand.php` 同时存在于根目录和 `recycle_device_brand/` 子目录
- 命名不一致：部分子目录使用 snake_case，部分使用 camelCase
- 业务领域混杂：设备、订单、报价、导入等多个业务模块混在一起

**影响：**
- 代码难以维护
- 容易产生命名冲突
- 新人难以快速理解项目结构

### 1.2 Service 层组织混乱

**问题描述：**
- `/addon/recycle/app/service/admin/` 目录存在 `order copy/` 备份目录未清理
- 根目录有6个服务文件，其他服务在子目录中，组织不统一
- 存在重复的服务类：`order/RecycleOrderService.php` 和 `recycle_order/RecycleOrderService.php`
- 命名规范不统一

**影响：**
- 代码冗余
- 维护困难
- 容易引用错误的服务类

### 1.3 订单签收流程Bug

**问题日志：**
```
[2026-02-03T19:55:35+08:00][error]
错误信息：fields not exists:[action]
位置：RecycleOrderService.php:395
```

**问题原因：**
- `update()` 方法中，`action` 参数（控制参数）被直接传递给数据库更新
- 第390-392行的 `foreach` 循环将所有请求参数复制到更新数据中
- 数据库表中不存在 `action`、`devices` 等字段，导致报错

**代码问题：**
```php
// 第369-376行：只处理了 order_cancel，没有处理 order_sign
if (isset($data['action'])) {
    switch ($data['action']) {
        case 'order_cancel':
            return $this->cancel($id, $data);
        default:
            break;  // order_sign 会继续往下执行
    }
}

// 第390-392行：致命的 foreach 循环
foreach ($data as $key => $value) {
    $update_data[$key] = $value;  // 包括 action、devices 等非数据库字段
}
```

### 1.4 第三方服务管理缺失

**现状：**
- 已对接：3023设备查询API、安果ERP快递服务、阿里快递查询
- 未来需求：更多快递服务商、短信服务、支付网关等

**问题：**
- 缺乏统一的第三方服务管理层
- 配置分散，难以管理
- 没有统一的费用追踪和余额管理
- 缺乏主备切换机制
- 扩展新服务需要重复编写相似代码

#### 3.3.3 核心服务层（Core Service）

```php
<?php
declare(strict_types=1);

namespace addon\recycle\app\service\core\third_party;

use core\base\BaseCoreService;
use core\exception\CommonException;
use think\facade\Db;
use think\facade\Log;

class CoreThirdPartyService extends BaseCoreService
{
    /**
     * 调用第三方服务
     * @param string $serviceType 服务类型
     * @param string $method 方法名
     * @param array $params 参数
     * @param int $siteId 站点ID
     * @return array
     */
    public function call(string $serviceType, string $method, array $params, int $siteId): array
    {
        // 1. 获取服务提供者（支持主备切换）
        $provider = $this->getProvider($serviceType, $siteId);

        // 2. 执行中间件（余额检查、限流、缓存等）
        $this->executeMiddleware($provider, $method, $params);

        // 3. 调用服务
        $startTime = microtime(true);
        try {
            $result = $provider->execute($method, $params);
            $duration = round((microtime(true) - $startTime) * 1000);

            // 4. 记录日志和费用
            $this->logApiCall($provider, $method, $params, $result, $duration, true);

            return $result;
        } catch (\Exception $e) {
            $duration = round((microtime(true) - $startTime) * 1000);

            // 5. 错误处理和重试
            $this->logApiCall($provider, $method, $params, [], $duration, false, $e->getMessage());

            // 尝试备用服务商
            return $this->tryBackupProvider($serviceType, $method, $params, $siteId);
        }
    }

    /**
     * 获取服务提供者（支持主备）
     */
    private function getProvider(string $serviceType, int $siteId)
    {
        $services = ThirdPartyService::where([
            ['site_id', '=', $siteId],
            ['service_type', '=', $serviceType],
            ['status', '=', ThirdPartyDict::STATUS_ENABLED]
        ])->order('priority', 'asc')->select();

        foreach ($services as $service) {
            $providerClass = $this->getProviderClass($service->provider_name);
            $provider = new $providerClass($service->config);

            if ($provider->healthCheck()) {
                return $provider;
            }
        }

        throw new CommonException('没有可用的服务提供者');
    }
}
```

#### 3.3.5 具体服务提供者示例

```php
<?php
declare(strict_types=1);

namespace addon\recycle\app\service\core\third_party\provider\device_query;

use addon\recycle\app\service\core\third_party\provider\BaseProvider;

class Provider3023 extends BaseProvider
{
    public function execute(string $method, array $params): array
    {
        switch ($method) {
            case 'queryByImei':
                return $this->queryByImei($params['imei']);
            case 'getActivationLock':
                return $this->getActivationLock($params['imei']);
            default:
                throw new \Exception("不支持的方法: {$method}");
        }
    }

    private function queryByImei(string $imei): array
    {
        // 调用3023 API
        $response = $this->httpPost($this->config['api_url'], [
            'imei' => $imei,
            'api_key' => $this->config['api_key']
        ]);

        return $this->parseResponse($response);
    }

    public function getBalance(): float
    {
        // 查询余额
        $response = $this->httpGet($this->config['balance_url']);
        return $response['balance'] ?? 0;
    }

    public function healthCheck(): bool
    {
        try {
            $balance = $this->getBalance();
            return $balance > 0;
        } catch (\Exception $e) {
            return false;
        }
    }

    public function getName(): string
    {
        return '3023设备查询';
    }
}
```

## 六、技术要点

### 6.1 NiuCloud 代码规范

1. **命名规范：**
   - 类名：PascalCase
   - 方法名：camelCase
   - 数据库字段：snake_case
   - 常量：UPPER_SNAKE_CASE

2. **继承规范：**
   - Admin端服务：继承 `BaseAdminService`
   - Core服务：继承 `BaseCoreService`
   - 模型：继承 `BaseModel`

3. **文件头规范：**
   ```php
   <?php
   declare(strict_types=1);

   namespace addon\recycle\app\...;
   ```

4. **异常处理：**
   - 使用 `CommonException` 抛出业务异常
   - 使用 `Db::startTrans()` 和 `Db::commit()` 处理事务

### 6.2 关键设计模式

1. **策略模式：** 不同服务提供者实现相同接口
2. **工厂模式：** 根据配置动态创建Provider实例
3. **中间件模式：** 可插拔的功能扩展
4. **主备模式：** 自动故障转移
