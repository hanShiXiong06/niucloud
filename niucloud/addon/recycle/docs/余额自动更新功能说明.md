# 余额自动更新功能说明

## 问题背景

很多第三方API在每次调用时，会在响应结果中返回余额信息，而不是提供单独的查询余额接口。例如：

**3023 设备查询API 响应示例**:
```json
{
    "code": 0,
    "message": "success",
    "data": {
        "sn": "C02XYZ123456",
        "model": "iPhone 13 Pro",
        ...
    },
    "cost": 0.05,
    "balance": 98.50  // 余额信息
}
```

如果每次都单独调用 `getBalance()` 方法查询余额，会：
1. 额外产生API调用费用
2. 增加响应时间
3. 浪费资源

## 解决方案

### ✅ 自动余额更新

架构已经实现了**自动余额更新**功能：

1. **每次API调用后自动检查**
   - 检查返回结果中是否包含余额信息
   - 支持两种位置：`result['balance']` 或 `result['data']['balance']`

2. **自动更新到数据库**
   - 如果找到余额信息，自动更新到 `third_party_service` 表的 `balance` 字段
   - 更新失败不影响主流程

3. **主备服务商都支持**
   - 主服务商调用成功后更新
   - 备用服务商调用成功后也更新

## 实现代码

### CoreThirdPartyService.php

```php
/**
 * 自动更新余额（如果返回结果中包含余额信息）
 */
private function updateBalanceIfExists(int $siteId, string $serviceType, string $providerName, array $result)
{
    try {
        // 检查返回结果中是否包含余额信息
        $balance = null;

        // 尝试从不同的位置获取余额
        if (isset($result['balance'])) {
            $balance = (float)$result['balance'];
        } elseif (isset($result['data']['balance'])) {
            $balance = (float)$result['data']['balance'];
        }

        // 如果找到余额信息，更新到数据库
        if ($balance !== null) {
            $service = ThirdPartyService::where([
                ['site_id', '=', $siteId],
                ['service_type', '=', $serviceType],
                ['provider_name', '=', $providerName]
            ])->find();

            if ($service) {
                $service->save(['balance' => $balance]);
                Log::info("自动更新余额: {$providerName} = {$balance}");
            }
        }
    } catch (\Exception $e) {
        // 余额更新失败不影响主流程
        Log::warning("自动更新余额失败: " . $e->getMessage());
    }
}
```

### 调用时机

```php
// 主服务商调用成功后
$result = $provider->execute($method, $params);
$this->updateBalanceIfExists($siteId, $serviceType, $provider->getProviderName(), $result);

// 备用服务商调用成功后
$result = $provider->execute($method, $params);
$this->updateBalanceIfExists($siteId, $serviceType, $provider->getProviderName(), $result);
```

## 支持的余额格式

### 格式1: 顶层 balance 字段
```json
{
    "code": 0,
    "data": {...},
    "balance": 98.50
}
```

### 格式2: data 中的 balance 字段
```json
{
    "code": 0,
    "data": {
        "result": {...},
        "balance": 98.50
    }

```

## 优势

### ✅ 节省费用
不需要单独调用 `getBalance()` 接口，避免额外的API调用费用。

### ✅ 实时更新
每次业务调用后，余额都会自动更新，保持最新状态。

### ✅ 透明处理
对业务代码完全透明，不需要任何额外的代码。

### ✅ 容错性好
余额更新失败不会影响主业务流程。

## 兼容性

### 有余额接口的服务商
如果服务商提供单独的余额查询接口（如3023的 `/user/balance`），可以：
1. 依赖自动更新（推荐）
2. 或者手动调用 `getBalance()` 方法

### 没有余额接口的服务商
如果服务商不提供余额查询接口（如阿里云市场API），可以：
1. 在 Provider 的 `getBalance()` 方法中返回 0
2. 依赖自动更新（如果响应中包含余额）
3. 或者手动在数据库中更新余额

## 监控建议

### 1. 定期检查余额
```sql
-- 查看余额低于告警阈值的服务
SELECT id, service_type, provider_name, balance, min_balance_alert
FROM saas_third_party_service
WHERE site_id = 100000
AND balance < min_balance_alert;
```

### 2. 查看余额变化趋势
```sql
-- 查看最近的余额更新记录（通过update_at字段）
SELECT id, service_type, provider_name, balance, update_at
FROM saas_third_party_service
WHERE site_id = 100000
ORDER BY update_at DESC;
```

### 3. 结合费用统计
```sql
-- 查看今日消费和当前余额
SELECT
    s.service_type,
    s.provider_name,
    s.balance as current_balance,
    COALESCE(c.total_cost, 0) as today_cost,
    COALESCE(c.total_calls, 0) as today_calls
FROM saas_third_party_service s
LEFT JOIN saas_third_party_cost_stats c
    ON s.site_id = c.site_id
    AND s.service_type = c.service_type
    AND s.provider_name = c.provider_name
    AND c.date = CURDATE()
WHERE s.site_id = 100000;
```

## 注意事项

1. **余额字段位置**: 如果第三方API的余额字段在其他位置，需要修改 `updateBalanceIfExists` 方法
2. **余额精度**: 余额会转换为 float 类型，注意精度问题
3. **并发更新**: 高并发情况下可能有多个请求同时更新余额，但这不会造成问题
4. **日志记录**: 每次自动更新都会记录日志，方便追踪

## 扩展

如果需要支持更多的余额格式，可以修改 `updateBalanceIfExists` 方法：

```php
// 支持更多格式
if (isset($result['balance'])) {
    $balance = (float)$result['balance'];
} elseif (isset($result['data']['balance'])) {
    $balance = (float)$result['data']['balance'];
} elseif (isset($result['user']['balance'])) {
    $balance = (float)$result['user']['balance'];
} elseif (isset($result['account']['balance'])) {
    $balance = (float)$result['account']['balance'];
}
```

余额自动更新功能已经完全集成到架构中，无需任何额外配置或代码，开箱即用。每次API调用后，如果响应中包含余额信息，都会自动更新到数据库，保持余额的实时性和准确性。
