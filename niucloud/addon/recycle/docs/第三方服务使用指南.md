## 二、快速开始

### 1. 配置服务提供商

在数据库中添加服务配置：

```sql
-- 配置3023设备查询服务
INSERT INTO `saas_third_party_service` VALUES (
    NULL,                           -- id
    100000,                         -- site_id (你的站点ID)
    'device_query',                 -- service_type
    '3023',                         -- provider_name
    1,                              -- priority (优先级，越小越优先)
    '{"base_url":"http://api.3023data.com","api_key":"your_api_key_here","timeout":30}',  -- config (JSON格式)
    1,                              -- status (1启用 0禁用)
    0.00,                           -- balance
    100.00,                         -- min_balance_alert
    UNIX_TIMESTAMP(),               -- create_at
    UNIX_TIMESTAMP()                -- update_at
);

-- 配置安果快递服务
```

### 2. 在业务代码中使用

#### 示例1：查询设备信息

```php
<?php
use addon\recycle\app\service\core\third_party\CoreThirdPartyService;

// 在你的Service类中
class RecycleOrderService extends BaseAdminService
{
    private $thirdPartyService;

    public function __construct()
    {
        parent::__construct();
        $this->thirdPartyService = new CoreThirdPartyService();
    }

    /**
     * 查询设备信息
     */
    public function queryDevice(string $imei)
    {
        try {
            $result = $this->thirdPartyService->call(
                'device_query',              // 服务类型
                'queryByImei',               // 方法名
                ['imei' => $imei],           // 参数
                $this->site_id               // 站点ID
            );

            if ($result['success']) {
                return $result['data'];
            }

            throw new CommonException('设备查询失败');

        } catch (\Exception $e) {
            throw new CommonException($e->getMessage());
        }
    }

    /**
     * 查询激活锁
     */
    public function checkActivationLock(string $imei)
    {
        $result = $this->thirdPartyService->call(
            'device_query',
            'getActivationLock',
            ['imei' => $imei],
            $this->site_id
        );

        return $result['data'];
    }
}
```

#### 示例2：创建快递订单

```php
<?php
/**
 * 创建快递订单
 */
public function createDeliveryOrder(int $orderId)
{
    // 获取订单信息
    $order = RecycleOrder::find($orderId);

    // 获取地址信息
    $senderAddress = $this->getSenderAddress();
    $receiveAddress = $order->address;

    // 调用快递服务
    $result = $this->thirdPartyService->call(
        'delivery',                  // 服务类型
        'createOrder',               // 方法名
        [
            'senderName' => $senderAddress['name'],
            'senderMobile' => $senderAddress['mobile'],
            'senderProvince' => $senderAddress['province'],
            'senderCity' => $senderAddress['city'],
            'senderDistrict' => $senderAddress['district'],
            'senderAddress' => $senderAddress['address'],

            'receiveName' => $receiveAddress['name'],
            'receiveMobile' => $receiveAddress['mobile'],
            'receiveProvince' => $receiveAddress['province'],
            'receiveCity' => $receiveAddress['city'],
            'receiveDistrict' => $receiveAddress['district'],
            'receiveAddress' => $receiveAddress['address'],

            'weight' => 1.0,
            'remark' => '回收订单',
            'deliveryType' => 'shunfeng',
        ],
        $this->site_id
    );

    // 保存运单号
    if ($result['success']) {
        $order->express_no = $result['data']['waybill_no'];
        $order->save();
    }

    return $result;
}
```

## 三、主备切换机制

系统会自动进行主备切换：

1. 配置多个服务提供商，设置不同的优先级
2. 主服务商调用失败时，自动切换到备用服务商
3. 所有调用都会记录日志

```sql
-- 配置主服务商（优先级1）
INSERT INTO `saas_third_party_service` VALUES (
    NULL, 100000, 'device_query', '3023', 1, '...', 1, 0, 100, ...
);

-- 配置备用服务商（优先级2）
INSERT INTO `saas_third_party_service` VALUES (
    NULL, 100000, 'device_query', 'backup_provider', 2, '...', 1, 0, 100, ...
);
```

## 七、注意事项

1. **配置格式**：config字段必须是有效的JSON格式
2. **优先级**：数字越小优先级越高，主服务商设置为1
3. **余额告警**：当余额低于min_balance_alert时会记录日志
4. **健康检查**：系统会自动检查服务商健康状态，不健康的会自动跳过
5. **日志记录**：所有API调用都会自动记录，包括成功和失败的
6. **费用统计**：每日自动统计费用和调用次数

## 八、故障排查

### 问题1：Provider类不存在

检查：
1. Provider类文件是否存在
2. 命名空间是否正确
3. 类名是否符合规范（Provider + 驼峰格式的provider_name）

### 问题2：健康检查失败

检查：
1. API配置是否正确（base_url, api_key等）
2. 网络是否可达
3. 余额是否充足

### 问题3：主备切换不生效

检查：
1. 是否配置了多个服务提供商
2. priority字段是否设置正确
3. 备用服务商的status是否为1（启用）

## 九、性能优化建议

1. **缓存机制**：对于设备查询等可缓存的数据，建议在业务层添加缓存
2. **异步调用**：对于非实时要求的API调用，可以使用队列异步处理
3. **批量操作**：如果Provider支持批量查询，优先使用批量接口
4. **超时设置**：根据实际情况调整timeout配置
