# 芯烨云API接口列表

根据文档和现有代码，以下是可用的芯烨云API接口：

## ✅ 已实现的接口

### 1. 打印标签订单
- **接口**: `/api/openapi/xprinter/printLabel`
- **状态**: ✅ 已实现
- **位置**: `TemplatePrintService::sendToPrinter()`
- **说明**: 用于标签打印机的打印功能

---

## 📋 可选的API接口（根据文档）

### 2. 添加打印机到开发者账户（可批量）【必接】
- **接口**: `/api/openapi/xprinter/addPrinters`
- **状态**: ⚠️ 需要确认
- **说明**: 打印之前必须调用本接口进行打印机注册，即添加PID或SN到开发者ID下
- **用途**: 管理打印机设备

### 3. 设置打印机语音类型
- **接口**: `/api/openapi/xprinter/setVoiceType`
- **状态**: ❌ 未实现
- **说明**: 设置打印机的语音提示类型
- **用途**: 打印机配置

### 4. 打印小票订单【票据机必接】
- **接口**: `/api/openapi/xprinter/print`
- **状态**: ❌ 未实现（您只使用标签打印机，不需要）
- **说明**: 用于小票打印机的打印功能

### 5. 删除打印机（可批量）
- **接口**: `/api/openapi/xprinter/delPrinters`
- **状态**: ❌ 未实现
- **说明**: 从开发者账户中删除打印机
- **用途**: 打印机管理

### 6. 修改打印机信息
- **接口**: `/api/openapi/xprinter/updPrinter`
- **状态**: ❌ 未实现
- **说明**: 修改打印机的配置信息
- **用途**: 打印机管理

### 7. 清空待打印队列
- **接口**: `/api/openapi/xprinter/delPrinterQueue`
- **状态**: ❌ 未实现
- **说明**: 清空指定打印机的待打印队列
- **用途**: 打印机管理

### 8. 查询订单是否打印成功 ⭐推荐
- **接口**: `/api/openapi/xprinter/queryOrderState`
- **状态**: ⚠️ SDK已存在，需要封装
- **说明**: 根据订单号查询打印状态
- **用途**: 打印状态追踪
- **返回**: 订单打印状态（0-待打印，1-已打印，2-打印失败）

### 9. 查询打印机某天的订单统计数
- **接口**: `/api/openapi/xprinter/queryOrderStatis`
- **状态**: ⚠️ SDK已存在，需要封装
- **说明**: 查询指定日期打印机的订单统计
- **用途**: 统计分析

### 10. 查询打印机状态 ⭐推荐
- **接口**: `/api/openapi/xprinter/queryPrinterStatus`
- **状态**: ⚠️ SDK已存在，需要封装
- **说明**: 查询单个打印机的在线状态
- **用途**: 设备监控
- **返回**: 
  - 0 - 离线
  - 1 - 在线正常
  - 2 - 在线不正常（异常一般是无纸，离线的判断是打印机与服务器失去联系超过30秒）

### 11. 批量查询打印机状态 ⭐推荐
- **接口**: `/api/openapi/xprinter/queryPrintersStatus`
- **状态**: ⚠️ SDK已存在，需要封装
- **说明**: 批量查询多个打印机的在线状态
- **用途**: 设备监控（批量）

### 12. 金额播报
- **接口**: `/api/openapi/xprinter/playVoice`
- **状态**: ❌ 未实现
- **说明**: 云喇叭播放语音（金额播报）
- **用途**: 语音提示

## 📌 建议实现的接口（按优先级）

### 优先级1（推荐）：核心功能
1. **查询打印机状态** - 用于监控打印机是否在线
2. **查询订单是否打印成功** - 用于追踪打印状态

### 优先级2（可选）：管理功能
3. **添加打印机** - 用于设备管理
4. **修改打印机信息** - 用于设备管理
5. **删除打印机** - 用于设备管理

### 优先级3（可选）：辅助功能
6. **查询订单统计** - 用于数据统计
7. **清空待打印队列** - 用于队列管理

---

## 💡 建议

根据您的使用场景（设备回收标签打印），建议实现：

1. ✅ **查询打印机状态** - 在打印前检查打印机是否在线
2. ✅ **查询订单是否打印成功** - 确认打印是否成功（可选）

这些接口可以帮助：
- 避免向离线打印机发送打印任务
- 提供打印状态反馈给用户
- 提升用户体验

---

## 注意

- 所有API接口都需要公共参数：`user`、`timestamp`、`sign`
- 签名算法：`SHA1(user + user_key + timestamp)`
- 请求格式：`Content-Type: application/json;charset=UTF-8`
