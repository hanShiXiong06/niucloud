# 模板可视化编辑器重构方案

## 一、项目可行性评估

### 1.1 技术栈评估 ✅

**前端技术栈：**
- ✅ Vue 3.2.45 - 支持Composition API，适合复杂组件开发
- ✅ Element Plus 2.7.4 - 成熟的UI组件库
- ✅ Tailwind CSS 3.2.4 - 快速样式开发
- ✅ SortableJS 1.15.0 - 已安装，可用于拖拽排序
- ✅ Pinia 2.0.30 - 状态管理，可参考poster.ts的实现

**后端技术栈：**
- ✅ ThinkPHP - MVC框架，支持分层架构
- ✅ 已有Model层：`RecyclePrinterTemplate`
- ✅ 已有Service层：`RecyclePrinterTemplateService`
- ✅ 已有Controller层：`PrinterTemplate`

**参考项目：**
- ✅ 项目内已有海报编辑器（poster）实现，可作为参考
- ✅ 已有JSON格式的模板数据结构支持

### 1.2 数据库结构评估 ✅

当前数据库字段已支持：
- ✅ `content` (text) - 存储JSON格式模板数据
- ✅ `html_content` (text) - 存储HTML预览
- ✅ `width`, `height` (int) - 模板尺寸
- ✅ `size` (varchar) - 模板尺寸规格（58mm, 80mm等）

**需要扩展的字段：**
- ⚠️ 可能需要添加字段存储元素配置的更多细节（如字体、颜色等）
- 建议：当前JSON格式可灵活扩展，暂时不需要增加字段

### 1.3 功能需求评估 ✅

| 功能需求 | 技术可行性 | 实现难度 | 参考实现 |
|---------|-----------|---------|---------|
| 可视化拖拽编辑 | ✅ | 中等 | poster.ts |
| 自定义标签尺寸 | ✅ | 简单 | 已有width/height |
| 位置定位（x,y） | ✅ | 简单 | 已有JSON结构 |
| 自动换行 | ✅ | 中等 | 需计算文本宽度 |
| 字体大小设置 | ✅ | 简单 | JSON中width_scale/height_scale |

### 1.4 风险评估 ⚠️

**低风险：**
- ✅ 技术栈成熟，社区支持好
- ✅ 有参考实现（poster编辑器）
- ✅ 数据结构已支持JSON格式

**中等风险：**
- ⚠️ 自动换行需要精确计算文本宽度（考虑字体、字号）
- ⚠️ 打印精度问题（需要与芯烨云API对接测试）

**建议：**
- 分阶段实现，先实现基础功能，再优化自动换行
- 保留XML编辑模式作为高级功能

## 二、MVC架构设计

### 2.1 架构分层

```
┌─────────────────────────────────────────┐
│          Controller 层                  │
│   (处理HTTP请求，参数验证)                │
└──────────────┬──────────────────────────┘
               │
┌──────────────▼──────────────────────────┐
│          Service 层                     │
│   (业务逻辑，数据转换)                    │
│  - TemplateRenderService                │
│  - TemplateConverterService             │
│  - TemplateValidatorService             │
└──────────────┬──────────────────────────┘
               │
┌──────────────▼──────────────────────────┐
│          Model 层                       │
│   (数据访问，字段处理)                    │
│  - RecyclePrinterTemplate               │
└─────────────────────────────────────────┘
```

### 2.2 目录结构设计

```
addon/recycle/app/
├── adminapi/controller/printer/
│   └── PrinterTemplate.php           # Controller层（精简）
│
├── service/admin/printer/
│   ├── RecyclePrinterTemplateService.php      # 基础CRUD服务
│   ├── template/                               # 模板相关服务
│   │   ├── TemplateRenderService.php          # 渲染服务（HTML预览）
│   │   ├── TemplateConverterService.php       # 转换服务（JSON↔XML）
│   │   ├── TemplateValidatorService.php       # 验证服务（数据校验）
│   │   └── TemplateLayoutService.php          # 布局服务（自动换行等）
│   └── element/                                # 元素相关服务
│       ├── ElementPositionService.php         # 位置计算服务
│       └── ElementTextService.php             # 文本处理服务
│
└── model/printer/
    └── RecyclePrinterTemplate.php             # Model层
```

### 2.3 职责划分

#### Controller 层职责
- ✅ 接收HTTP请求
- ✅ 参数验证（使用ThinkPHP验证器）
- ✅ 调用Service层方法
- ✅ 返回响应结果
- ❌ 不包含业务逻辑
- ❌ 不直接操作数据库

#### Service 层职责
- ✅ 业务逻辑处理
- ✅ 数据格式转换（JSON ↔ XML）
- ✅ 模板渲染（生成HTML预览）
- ✅ 数据验证（模板结构、元素配置）
- ✅ 布局计算（自动换行、位置计算）
- ❌ 不直接操作数据库（通过Model）

#### Model 层职责
- ✅ 数据库操作（CRUD）
- ✅ 字段访问器/修改器
- ✅ 数据格式转换（JSON字段自动处理）
- ✅ 软删除支持
- ❌ 不包含业务逻辑

### 3.2 数据模型设计

#### TemplateElement 接口（前端）
```typescript
interface TemplateElement {
  id: string;                    // 元素唯一ID
  type: 'text' | 'qrcode' | 'barcode' | 'line' | 'rectangle' | 'variable';
  x: number;                      // X坐标（dot单位）
  y: number;                      // Y坐标（dot单位）
  width?: number;                 // 宽度（用于矩形、线条）
  height?: number;                // 高度（用于矩形、线条）
  content?: string;               // 内容（文本、变量、二维码内容）
  
  // 文本/变量特有属性
  width_scale?: number;           // 宽度缩放（1-8）
  height_scale?: number;          // 高度缩放（1-8）
  rotation?: number;              // 旋转角度（0-360）
  font_size?: number;             // 字体大小（前端预览用）
  font_color?: string;            // 字体颜色（前端预览用）
  text_align?: 'left' | 'center' | 'right'; // 文本对齐
  word_wrap?: boolean;            // 是否自动换行
  
  // 二维码特有属性
  size?: number;                  // 二维码尺寸（1-10）
  error_level?: 'L' | 'M' | 'Q' | 'H'; // 纠错级别
  
  // 条形码特有属性
  scale?: number;                 // 条形码缩放（1-6）
  
  // 矩形特有属性
  xe?: number;                    // 终点X坐标
  ye?: number;                    // 终点Y坐标
  style?: number;                 // 边框样式（0-4）
  
  // 布局计算属性（前端使用，不存储）
  calculated_width?: number;      // 计算后的宽度（像素）
  calculated_height?: number;     // 计算后的高度（像素）
  lines?: string[];               // 换行后的文本行数组
}
```

#### Template 接口（前端）
```typescript
interface Template {
  width: number;                  // 模板宽度（dot单位）
  height: number;                 // 模板高度（dot单位）
  size: string;                   // 模板尺寸规格（58mm, 80mm等）
  elements: TemplateElement[];    // 元素列表
}
```
