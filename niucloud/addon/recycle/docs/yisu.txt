保价
部分快递和渠道暂不支持保价， 将返回”不支持保价”。
不支持保价的快递： 极兔 以及其他快递部分渠道
部分渠道有强制保价请联系客服确认
保费如存在小数 则向上取整
取消订单
目前仅支持待取件状态订单取消， 如其他订单状态取消请联系客服
重货订单，1小时内禁止取消，如需取消请联系快递员处理
未生成（回传/推送）快递单号的订单禁止取消， 如需取消请联系客服处理。

签名规则
将appid, version, timeStamp, secretKey四个字符串参数依照此顺序拼接，得到的长字符串进行md5（32位）加密生成签名sign。appSecret只参与加签过程，不参与请求传输，请妥善保管。
签名示例
public static String getSign(String appid, String version, String timeStamp, String appSecret) {
    StringBuilder sb = new StringBuilder(appid).append(version).append(timeStamp).append(appSecret);
    return  SecureUtil.md5(sb.toString());
}

推送接口
简要描述
物流信息变更时通知商户，商户可做相应操作
回调URL
商户可将回调地址发给我们进行配置
请求类型
application/json
回调方式
POST
回调参数
参数名	必选	类型	说明
thirdOrderNo	是	string	商户订单号
waybillNo	是	string	快递运单号，下单时没有的将通过状态变更通知，实际状态不一定有变更
orderNo	是	string	平台订单号
type	是	string	详见快递列表
pushType	是	string	推送类型 1状态变更 2计费变更 3快递员变更 4订单变更
data	是	object	推送信息对象, 根据推送类型决定
data-状态变更	-	-	-
status	是	string	订单状态 1：待取件 2：运输中 5：已签收 6：取消订单 7：终止揽收 8：特殊关闭 9：已退款
desc	是	string	订单描述
data-计费变更	-	-	-
originalFee	是	number	官方原价
weightFinal	是	number	真实重量(kg)
weightFee	是	number	计费重量 (kg)
volume	是	number	体积 (立方米)
productCode	是	string	快递公司产品代码 详见快递公司产品
productName	是	string	快递产品代码名称
ifOriginalFee	是	boolean	是否按原价计费(否false,是true)
totalFee	是	number	总费用(元)
等于费用类型的
(1+2+…+8)-9
feeList	是	array	费用明细
feeList.type	是	int	费用类型 1运费,2真实保价费用,
3耗材费,4技术服务费,
5转寄费,6加重费,
7加长费,8其他费
9退款费用(退款给用户，金额是正数)
feeList.name	是	string	费用名称
feeList.fee	是	number	费用金额(元)
data-快递员变更	-	-	-
courierInfo	是	string	揽收信息，不同订单类型格式不同，请自行解析
courierPhone	是	string	揽收员电话
data-订单变更	-	-	-
newWaybillNo	是	string	新运单号，不会覆盖原订单号，原订单号依然可查询
返回说明
接收到信息后请在2秒内返回字符串”SUCCESS”,大写，否则视为失败

"SUCCESS"
