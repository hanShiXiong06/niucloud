# 在电脑后台接入博远

进入站点后台 **ERP → 工作台 → 博远对接工作台 → 填写连接信息**。在博远菜单中可随时点「连接设置」，ERP 的期初建账页也保留同一个工作台入口。管理员负责接入；店员从原采购单和销售单处理业务。

1. 打开「连接设置」。向博远对接人取得同一环境的 **服务地址 URL、公司代码（账套 ID）、AppID、AppSecret（AppSec）**。测试与正式环境不可混用。服务地址有默认值；AppID 和公司代码按文本保留前导零。
2. 点击「保存连接」。保存不会发单、不会开启同步、也不表示已核验。密钥不回显；不更换连接身份时可留空保留。只有确认开通采购接口后才勾选对应选项。
3. 点击「核验已保存的账套」。博远返回匹配的账套才会显示「已核验」。进入「准备基础资料」，按需逐项读取档案，再按业务需要确认期初建账。
   对已核验的正式或测试开放平台连接，点击「取回此项」会在当前页面读取该类档案。已有等待任务可点「现在取回」。只写本站博远档案库；不会新建 ERP 仓库、创建单据或启用全站队列。一次最多读取 25 页；离开或中断后可从原进度继续。
4. 在支持的测试账套中，管理员可在「期初建账 → 手动同步设置」核对账套后开启投递。店员按原流程在 ERP 采购入库单、同行挂账销售单上补齐缺项，确认同步并查看博远单号。暂停投递不删除旧单；保存或核验连接不等于业务单据已发送。
5. 正式采购在「连接设置 → 正式采购同步」开启。系统展示本站已核验的测试采购或已登记的上线依据，管理员核对目标正式账套后确认；测试单号不是正式业务单号。没有符合条件的记录时不会打开投递，也不要求店员随便填一个编号。
6. 对启用前已入库且仍在库的单台设备，从原 ERP 采购单点击「核对并同步博远 → 准备这张原采购单」。此时只生成草稿。核对博远商品、仓库和金额，再提交。发送前会查原业务日的采购串号和当前库存；查到冲突或查不清均不建单。不批量重放，不重开本地采购，不登记付款。生产付款登记尚未开放；本地已付不等于博远已冲销原采购。

开工后，工作台「日常业务」按当前员工权限显示回收录单、按设备付款、商城交付和收回挂账；日常业务不需要等待博远回执。卖已上架设备从商城交付，不要再从 ERP 重复开销售单。

如果菜单没有出现：确认本站已启用 ERP 与博远插件、博远已升级到 1.3.0、公共组件 hsx_components 已更新到 0.1.1，PC 管理端资源已编译更新。刷新后台。普通员工还须被授予相应页面及操作权限；能查看设置并不等于能修改或核验。

**查客户电话**：客户把手机号填在博远的助记码时，在「连接设置 → 客户供应商电话取自」选择「助记码（help_code）」。原已选「约定电话」的账套无需重新设置。正常同步后，在「基础资料 → 客户与供应商」直接看完整手机号，点号码即可复制，支持用完整号码搜索。不用逐条向博远查询；助记码为空也不会取其他字段顶替。

**浏览所有已取回的资料**：直接进入「博远对接 → 基础资料」，左侧选类别，右侧搜索或翻页，点击蓝色名称查看详情。公司门店、仓库、分类、品牌、商品型号、业务人员、客户供应商、会员档案、收银方式、资金账户共用这个入口。字段有中文说明，勾「显示接口字段名」可对照原名，默认保留空值；新出现的字段也显示。这里只读，不更新博远、不建 ERP 档、不重新排队。

员工沿用本站查看档案的权限（查看同步进度、搜索基础资料），不要求管理员逐条授权。客户助记码按博远原值保存在本站往来单位档案；无档案权限的业务选择器不返回该原值。密钥、银行卡和证件号码的保护不变。

**旧电话显示「需重新读取」**：在「期初建账 → 客户供应商」点一次「重新读取」。旧版本没有保存的完整号码不能从星号还原；只需更新该类档案，不用重新建账。
