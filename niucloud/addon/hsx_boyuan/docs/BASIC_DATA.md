# 博远基础资料同步

## 范围与方向

博远是这些外部档案的来源。插件以只读API拉取到按站点、环境和连接隔离的档案库，再由员工选择本地ERP已有资料建立对应。不是向博远上传主档，也不自动覆盖本地ERP主档、创建登录账号、合并会员或导入库存。没有对应的本地资料时可先完成外部档案拉取，稍后再对应。

单据和财务写入不在本次范围。开放平台协议在服务端阻止开启业务自动投递，支付、退款、创建单据等service不在客户端白名单中。原模拟器仅用于隔离回归，不代表博远实现了其协议。

## 配置

- 模拟、UAT测试、正式分别保存连接，不能共用档案或密钥。
- 接入协议选“博远开放平台 v1.5.3”。文档版本不等于请求版本，请求固定为1.0。
- 服务基础地址、网关路径分别保存；本轮按用户最新提供的UAT域名及 `/api/gateway.do` 实际核验通过，不自动尝试文档中的其他旧域名。
- AppID、AppSecret、账套代码 `big_gsdm` 分开输入。账套代码不是门店UUID；门店和仓库另行对应。
- AppSecret通过站点及连接绑定的AES-GCM加密保存，公开接口不回传。MD5签名按参数名排序，使用原始值再追加密钥计算；表单编码在签名之后进行。
- 先保存，再“核验已保存账套”。核验要求接口返回的启用公司代码确实匹配，不能只凭HTTP200通过。
- 会员档案按注册日期查询，起始日期可选，默认2000-01-01，截止日期为任务创建当日。范围会冻结在任务中，不在翻页期间悄悄改变。
- 修改目标地址、网关、AppID或账套生成新的连接身份，需重新授权和核验；旧任务与档案保留在原连接。

## 十类档案

| 档案 | 博远service | 对应用途 |
| --- | --- | --- |
| 公司门店 | boyuan.companys.get | 核验账套、区分公司及门店 |
| 分类 | boyuan.categorys.get | 分类名称、编码和上下级 |
| 品牌 | boyuan.brands.get | 品牌ID和名称 |
| 商品型号 | boyuan.products.get | 商品ID、型号、内存、颜色和串号规则 |
| 仓库 | boyuan.warehouses.get | 选择博远仓库与本地仓库对应 |
| 业务人员 | boyuan.users.get | 业务员对应，不创建登录账户 |
| 客户供应商 | boyuan.custsuppliers.get | 分别校验客户/供应商属性，不按同名合并 |
| 会员档案 | boyuan.members.get | 注册日期范围内的只读档案，不覆盖本站会员 |
| 收银方式 | boyuan.cashinfos.get | 收银方式对应，不执行收款 |
| 资金账户 | boyuan.account.get | 资金账户ID对应，不保存银行账号全文 |

文档没有提供独立库位读取和客户通用CRUD，本版不伪造这两种能力。分类、品牌、门店和会员先作为参考档案，不强行绑定成不同语义的ERP主档。

## 同步与异常

“同步全部”和单类刷新均创建异步任务。重复点击复用尚在执行的同类任务；每次计划任务分批读取，显示已处理行数、页数、最近成功时间。每页采用事务保存，失败不推进游标；有限自动重试后可从原分页人工续传。

重复拉取按外部ID更新，不重复创建档案。上游明确停用则保持停用；接口未返回启用状态时标记“状态未提供”，不假定启用。上游没有返回某记录不等于已删除，不删除旧档案或现有对应。

建立新对应只能选择最近一轮完整同步确认过的档案。旧记录若未在该轮再次返回，保留为待核对缓存，不把它伪装成当前可用档案；已有对应和业务记录不会因此被删除。

停用且缺名称的档案可保留，并明确显示上游未提供名称，不编造真实名称，也不可作为启用档案选用。启用档案缺名称、缺稳定ID、分页不前进、返回失败均作为异常处理。结束时按本轮唯一ID数核对远端总数，不一致进入“数量待核对”，不能报整类完整成功。

手机号只保存站点隔离的HMAC和掩码；检索使用完整号码匹配HMAC，正常手机界面通过POST发送搜索词，不把手机号放进查询URL。身份证号、地址、积分、银行账号等非本次所需字段不写入档案库。多个同号码的记录分别保留，由员工核对，不自动合并。

商品、客户、供应商和人员需要对应时，可先选博远档案，再从本站有效资料中选择。保存会校验本地资料属于本站且未停用、远端档案属于当前连接且可用，使用版本号防止覆盖他人的修改。内部ID自动带入，技术编号只读折叠展示。修改对应不改写已发出的任务快照。

1.1.1手机端在开放平台模式下只保留商品、人员、客户、供应商四类对应Tab，各类独立搜索和分页。仓库、资金账户和收银方式在基础资料中只读管理，不要求人工对应。模拟/旧桥接协议仍保留其原契约需要的对应选项，不代表博远新接口的设计。

人员或往来单位可按本站手机号在当前完整同步、启用的博远档案中查找候选。只返回脱敏手机号，不返回手机号哈希。唯一匹配也须人工核对；多条匹配选择其中一条再保存，保存后编辑直接复用现有绑定。缺号、无匹配或未完整同步都有手动搜索或更新资料入口；不会自动创建登录账号或覆盖原有绑定。管理员的博远人员ID不能重复绑定给另一位本站人员。角色标记用于支持同一往来主体既是客户又是供应商。

当前只是资料读取、选择与绑定的体验升级，**尚未实现整个ERP的数据来源切换或停用全部旧ERP数据**，不能通过隐藏Tab声称完成该功能。商品建档、往来单位查找或创建仍待博远补充真实契约。商品型号、品牌、内存、颜色及版本保持独立字段，不从展示名猜测规格。

## 安装与验收边界

本版新增 `hsx_boyuan_reference`、`hsx_boyuan_reference_sync` 两张插件表，通过安装/升级钩子幂等创建。手机端需要重新编译，并授予新增的同步、查询和对应权限。未改核心框架，未清空业务表。

本地隔离验收使用真实插件服务和实际手机页面，原生基础控件经浏览器适配。它不代替正式站点安装、正常登录权限、小程序真机和生产环境验收。UAT验收库中的本地演示仓明确为虚构资料，仅用于验证对应流程。
