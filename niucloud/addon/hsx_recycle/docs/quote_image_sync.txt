报价图片自动同步（回收基础插件）

一、功能边界
从已支持的 huishoubaojia.com 商户报价站读取公开图片，按明确映射更新本站报价分类。
不识别长图内的型号或价格，不修改型号库、订单、库存、财务、分类名称/封面/VIP/排序/显示设置。
原图及水印保留；请确保你有权使用来源图片。不绕过登录、验证码或访问限制。
不新增数据库表或字段。配置、进度及最近10次摘要使用已有 sys_config；报价版本使用已有 recycle_category_quote_history。

二、部署（手工覆盖方式）
1. 更新本次 hsx_recycle 插件后端、admin 源码，包括 app/dict/schedule/schedule.php。
2. 将插件 admin 同步到项目 admin/src/addon/hsx_recycle（本地工作目录已经同步），重新打包并发布 PC 后台。
   本次联调另修复了客户报价页手工拼接图片地址的问题：同步插件 uni-app/pages/price.vue
   到 uni-app/src/addon/hsx_recycle/pages/price.vue，并重新打包客户前端。移动管理端不涉及。
3. 在 niucloud 后端根目录先只读预览：
   php addon/hsx_recycle/scripts/register_quote_image_sync.php
   确认后执行：
   php addon/hsx_recycle/scripts/register_quote_image_sync.php --apply
   只补本功能计划任务，保留已有任务的启停，不执行采集、不更改业务数据、不建表。
   新安装走插件安装流程会自动注册；正常插件升级也会补注册。
4. 确认框架 queue.state 已开启、Redis 和框架队列消费者正常；沿用服务器现有进程管理，不另起一套调度。
5. 按当前部署方式重载计划任务进程，使其读到新增任务。后台计划任务可看到“报价图片每日自动采集”。
   任务每5分钟检查本站设定时间，不代表每5分钟下载图片。
6. PHP 8.0 及以上，需 DOM、cURL、OpenSSL、zlib（PNG流式校验）；来源 HTTPS 证书校验不能关闭，服务器需能解析并访问来源站/图片域。
   图片复用框架现有上传/存储服务，自动使用本站的存储配置，按框架规则回退平台默认配置。
   已配置云存储时直接交给对应驱动上传；本功能不单独配置厂商或密钥，不强制保存本地。
   存储权限和容量需足够；上传失败保留原报价。
本功能所有业务代码均在插件内，没有新增框架改动。

已有本功能站点的慢图超时/长PNG补丁：
仅覆盖 app/service/core/quote_image/HuishouBaojiaSource.php，并按原进程管理方式重启既有队列/调度。
不需要改数据库、重打前端或重复注册计划任务；不要额外再启动第二套队列。
进程启动应使用原项目指定的 PHP 解释器绝对路径，不能仅凭网站的 PHP 版本推断命令行版本。

三、管理员首次使用
1. 回收 → 报价分类 → 自动采集报价。
2. 填来源根地址，默认 https://13303016666.huishoubaojia.com/，点击读取来源栏目。
3. 每行选择本站报价分类。手机/华为与平板/华为按来源分组区分，不按同名自动猜测。
   没选分类的行不会采集；公共站点0和其他站点分类不能作为目标。
   同一个本站分类不能同时启用两个来源，最多32条映射。
4. 保存配置。立即采集会替换已启用映射的分类报价图片，并保存历史，不影响分类其他属性。
5. 先点击立即采集并查看每个栏目结果；成功后在报价分类及客户前端检查图片/历史版本。
6. 开启每日自动同步，选择北京时间的每日时间并保存。默认09:30，实际启动可能晚0～5分钟。
   每天最多自动尝试一次；当天失败可排查原因后手动重试。全局自动开关关闭时，仍可手动采集。

四、进度与兜底
任务是异步的，排队不等于已同步。抽屉显示排队/运行/成功/部分失败/失败、逐项原因与最近10次摘要。
每次队列任务只处理一个栏目，完成后再投递下一项。重复点击复用正在运行的任务。
只有该栏目全部图片下载、校验和本站转存成功，才事务更新分类图片并保留旧图备份、新图历史和检查点。
图片内容未变化不重复上传，不以URL是否变化作为唯一依据；图片采用新路径保存，旧历史不会被覆盖。
下载/转存失败、HTTP异常、页面改版或栏目撤下：保留原报价，不清空、不显示假成功。
大图缓冲：来源连接最多等待15秒，页面请求最多30秒，每张图片请求最多120秒。
同一请求的所有重定向共用上述预算，不会每跳重新计时；超时仍明确提示并保留原报价。
长PNG支持：旧版本把超过2000万像素也归为“图片无效”，会误拒正常报价长图。
2026-10-28只读核对来源：OPPO报价图779×26299（20486921像素）、VIVO报价图779×31125（24246375像素），
都是正常PNG且小于12MB，但旧版2000万像素校验会拒绝；这不代表补丁已部署或线上已验收。
当前PNG最多6000万像素；宽最多20000、高最多60000，JPEG/WebP仍保留2000万像素限制。
PNG校验使用有界内存的块边界/CRC与流式解压检查（包括交错PNG扫描行），不再创建整张GD位图。
上述两张真实原图在PHP8.0、64MB限制下已通过新校验，测试进程峰值约8MB；未上传或修改线上数据。
这是原图完整性校验与原样转存，不压缩、不缩小、不裁切；损坏、截断或超界图片仍明确报错并保留旧报价。
单图12MB、每栏目合计24MB及最多10张图片的安全限制不变。
云存储上传仍使用框架现有驱动及其配置，本补丁不修改上传SDK超时或其他业务的等待时间。
若上次同步后的本站图片被人工修改，系统会暂停该映射以保护人工版本。
核对后重新启用该行并保存，表示允许重新由来源图片接管；再次采集会重新建立基线。
停止本次只阻止未完成栏目和迟到任务写入，不撤销已经成功的图片。停止后可修改配置或重新采集。
30分钟无进度会标记失败，避免永久黑盒；请检查队列/网络/存储，可停止或重试。
遗留的重复/旧任务有运行ID和配置版本隔离，不会覆盖新任务或其他站点。
采集会清理报价分类缓存，客户仍按原访问权限和显示规则查看。

五、权限
查看继承报价分类查看权限；设置、采集、停止继承报价分类编辑权限；站点管理员可直接使用。
不自动给员工新增角色或权限。

七、停用/回退
在抽屉停止本次，再关闭自动开关或暂停相关映射；已经保存的报价与历史继续保留。
需要回到手工上传时，暂停映射后使用原分类编辑功能上传图片。
不要为回退删除分类或历史表。关闭本功能不会自动恢复旧版本，请从已有历史查看并按原流程选择需要的报价。
