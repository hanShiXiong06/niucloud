# 设备质检底部操作栏优化与测试

## 问题与修复

入口：回收订单列表 → 设备质检。

旧样式对 footer 多次覆盖，在 980px / 768px 以下强制把四个按钮竖排；footer 未撑满父容器，导致平板上按钮集中在中间，操作区占用过高。

本次只调整该弹窗的 footer 模板与样式：

- 合并底部布局规则，容器占满可用宽度。
- 宽屏将进度、下一步定价负责人、操作按钮排列在一行；空间不足时分成信息行和按钮行。
- 平板保持按钮横排；640px 及以下将按钮排列为两列。
- 只突出“完成质检”主按钮，“暂存草稿”降为普通操作，“退回设备”保留危险操作提示色。
- 保留四个原有回调及退回权限，暂存或提交期间禁用负责人切换。
- 不改质检业务脚本，不改接口、数据库或公共框架。

## 更新文件

两个文件内容保持一致：

1. `admin/src/addon/hsx_recycle/views/recycle_order/components/CheckDeviceDialog.vue`
2. `niucloud/addon/hsx_recycle/admin/views/recycle_order/components/CheckDeviceDialog.vue`

第二份为插件发布源码，避免后续插件同步覆盖修复。正式环境需要重新构建、发布管理端；仅替换 Vue 源文件不会改变已发布的静态页面。不需要数据库升级。
