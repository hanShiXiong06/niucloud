# 财务插件流程图设计

## 目标

这份文档用于给店内财务审核流程。

系统目标不是替代专业财务，而是把日常经营中的业务单据、应收应付、收付款、折账、经营费用、利润分析统一记录清楚，方便财务对账、老板看经营情况。

适用场景：

- 手机回收
- 二手机销售
- 同行批发
- 客户既供货又拿货
- 日常经营费用记录
- 应收应付管理
- 折账抵扣
- 利润统计

## 1. 财务插件总流程

```mermaid
flowchart TD
    A[业务发生] --> B{业务类型}

    B --> C[回收/采购入库]
    B --> D[销售/批发出库]
    B --> E[日常经营费用]
    B --> F[退款/退货]
    B --> G[手工调账]

    C --> C1[生成应付单]
    D --> D1[生成应收单]
    E --> E1[生成费用单]
    F --> F1[生成退款/反向单据]
    G --> G1[生成调账单]

    C1 --> H[财务待处理]
    D1 --> H
    E1 --> H
    F1 --> H
    G1 --> H

    H --> I{处理方式}
    I --> J[收款]
    I --> K[付款]
    I --> L[折账抵扣]
    I --> M[部分结算]
    I --> N[作废/红冲]

    J --> O[资金流水]
    K --> O
    L --> O
    M --> O
    N --> O

    O --> P[往来账]
    O --> Q[资金账户]
    O --> R[利润报表]
    O --> S[经营费用报表]
    O --> T[老板经营看板]
```

## 2. 往来单位账流程

同一个人可能既是上游，也是下游。

例如：

- 他给我们货，我们欠他钱，产生应付。
- 他从我们这里拿货，他欠我们钱，产生应收。
- 两边可以互相折账。

所以系统不建议分成单独的客户表、供应商表，而是统一为“往来单位”。

```mermaid
flowchart TD
    A[往来单位: 客户/同行/供应商] --> B{发生业务}

    B --> C[他给我货]
    B --> D[他拿我货]
    B --> E[我付他钱]
    B --> F[他付我钱]
    B --> G[双方折账]

    C --> C1[生成应付]
    D --> D1[生成应收]
    E --> E1[付款核销应付]
    F --> F1[收款核销应收]
    G --> G1[应收应付互相抵扣]

    C1 --> H[往来账余额]
    D1 --> H
    E1 --> H
    F1 --> H
    G1 --> H

    H --> I[应收余额]
    H --> J[应付余额]
    H --> K[净额]
    H --> L[未结清单据]
```

### 财务需要确认

- 是否接受“客户、供应商、同行统一为往来单位”的设计？
- 是否需要给往来单位增加信用额度？
- 是否需要结算周期，例如日结、周结、月结？
- 是否需要区分个人、公司、同行、平台？

## 3. 回收入库产生应付

```mermaid
flowchart TD
    A[回收订单成交] --> B[机器到店/确认入库]
    B --> C[质检确认]
    C --> D[确认最终回收价]
    D --> E[生成资产档案]
    D --> F[生成应付单]

    F --> G{是否立即付款}
    G -->|是| H[付款单]
    G -->|否| I[挂应付账]

    H --> J[资金账户减少]
    H --> K[核销应付]
    I --> L[进入应付账款列表]

    K --> M[往来单位账本]
    L --> M
```

### 注意事项

- 回收价格确认后才建议生成正式应付。
- 如果质检后改价，需要保留改价记录。
- 已经付款的应付单不能直接删除，只能走红冲或反向调整。

## 4. 销售出库产生应收

```mermaid
flowchart TD
    A[选择库存机器] --> B[创建销售单]
    B --> C[确认销售价格]
    C --> D[锁定库存]
    D --> E[确认出库]
    E --> F[生成应收单]

    F --> G{是否立即收款}
    G -->|是| H[收款单]
    G -->|否| I[挂应收账]

    H --> J[资金账户增加]
    H --> K[核销应收]
    I --> L[进入应收账款列表]

    K --> M[往来单位账本]
    L --> M
```

### 注意事项

- 销售出库前需要锁定库存，避免同一台机器重复销售。
- 同行批发可以先出库后挂账。
- 商城订单可以自动生成销售单和应收单。

## 5. 折账流程

折账是这个系统的重点。

例如：

```text
张三给我们一台机器，应付 3000。
张三又从我们这里拿一台机器，应收 4500。
财务做折账后，系统显示还需要收张三 1500。
```

```mermaid
flowchart TD
    A[选择往来单位] --> B[查看应收余额]
    A --> C[查看应付余额]

    B --> D[选择要抵扣的应收单]
    C --> E[选择要抵扣的应付单]

    D --> F[系统计算可折账金额]
    E --> F

    F --> G{财务确认}
    G -->|确认| H[生成折账单]
    G -->|取消| I[不处理]

    H --> J[核销应收]
    H --> K[核销应付]
    H --> L[生成折账流水]
    H --> M[更新往来单位余额]

    M --> N[显示净应收/净应付]
```

### 折账规则建议

- 折账必须生成独立折账单。
- 折账不能只修改余额。
- 折账单需要记录操作人、时间、应收单、应付单、抵扣金额、备注。
- 折账后如果要撤销，不能直接删除，应走作废或反向折账。
- 大额折账建议需要主管审核。

### 财务需要确认

- 折账是否允许部分抵扣？
- 折账是否需要审核？
- 折账作废由谁操作？
- 折账是否需要打印或导出对账单？

## 6. 日常经营费用流程

财务插件不能只看业务收入和成本，还要看经营费用。

常见费用：

- 房租
- 水电
- 工资
- 物流费
- 维修费
- 平台费
- 办公用品
- 招待费
- 广告推广
- 交通差旅
- 设备耗材
- 其他日常消费

```mermaid
flowchart TD
    A[发生经营费用] --> B[创建费用单]
    B --> C[选择费用分类]
    C --> D[填写金额/日期/经办人]
    D --> E[上传凭证]
    E --> F{是否需要审核}

    F -->|需要| G[主管审核]
    F -->|不需要| H[直接确认]

    G -->|通过| I[生成付款记录]
    G -->|驳回| J[退回修改]
    H --> I

    I --> K[资金账户减少]
    I --> L[经营费用报表]
    I --> M[利润分析]
```

### 费用分类建议

| 一级分类 | 二级分类示例 |
| --- | --- |
| 场地费用 | 房租、物业、水电、网络 |
| 人员费用 | 工资、提成、社保、奖金 |
| 交易费用 | 物流费、包装费、平台服务费、支付手续费 |
| 维修费用 | 配件、维修人工、检测费用 |
| 推广费用 | 广告、短视频投流、地推物料 |
| 办公费用 | 办公用品、打印耗材、设备维修 |
| 招待差旅 | 餐饮、交通、住宿 |
| 其他费用 | 临时费用、无法归类费用 |

### 财务需要确认

- 费用分类是否够用？
- 是否需要按门店、员工、业务线分摊费用？
- 是否需要上传发票或付款截图？
- 哪些费用需要审批？

## 7. 资金账户流程

系统需要记录钱从哪个账户进出。

账户示例：

- 现金
- 微信
- 支付宝
- 银行卡
- 对公账户
- 平台账户
- 员工备用金

```mermaid
flowchart TD
    A[收款/付款/退款/费用/折账] --> B{是否涉及实际资金}

    B -->|涉及| C[选择资金账户]
    B -->|不涉及| D[只生成账务流水]

    C --> E[生成资金流水]
    D --> F[生成非现金账务流水]

    E --> G[账户余额变化]
    F --> H[往来账变化]

    G --> I[资金账户报表]
    H --> J[往来单位对账单]
```

### 注意事项

- 折账通常不产生实际资金进出，但会影响应收应付余额。
- 收款、付款、退款、费用支出会影响资金账户余额。
- 资金账户流水不能随意删除。

## 8. 退款和退货流程

```mermaid
flowchart TD
    A[客户退货/业务取消] --> B{原业务类型}

    B --> C[销售退货]
    B --> D[回收退回]
    B --> E[费用冲销]

    C --> C1[资产回库]
    C --> C2[反向应收/退款]

    D --> D1[资产退回给上游]
    D --> D2[反向应付/追回已付款]

    E --> E1[费用红冲]

    C2 --> F[生成反向单据]
    D2 --> F
    E1 --> F

    F --> G[更新往来账]
    F --> H[更新资金流水]
    F --> I[保留操作日志]
```

### 注意事项

- 不建议直接删除原始单据。
- 退款、退货、冲销都要生成反向记录。
- 已结算单据发生退货，需要重新计算利润。

## 9. 调账流程

调账用于修正历史错误或特殊情况。

```mermaid
flowchart TD
    A[发现账务异常] --> B[创建调账申请]
    B --> C[选择调账类型]
    C --> D[填写原因和金额]
    D --> E[上传凭证]
    E --> F[主管审核]

    F -->|通过| G[生成调账单]
    F -->|驳回| H[退回]

    G --> I[更新应收/应付/资金账户]
    G --> J[写入审计日志]
    G --> K[影响报表]
```

### 调账类型示例

- 应收调增
- 应收调减
- 应付调增
- 应付调减
- 资金账户调增
- 资金账户调减
- 成本调整
- 费用调整

### 财务需要确认

- 哪些人可以发起调账？
- 哪些人可以审核调账？
- 多大金额需要老板审核？
- 调账是否允许影响历史利润？

## 10. 报表流程

```mermaid
flowchart TD
    A[业务收入] --> P[利润分析]
    B[商品成本] --> P
    C[维修成本] --> P
    D[物流成本] --> P
    E[平台费用] --> P
    F[人工工资] --> P
    G[房租水电] --> P
    H[日常费用] --> P
    I[退款退货] --> P
    J[折账影响] --> P

    P --> R[经营利润]
    P --> S[单机利润]
    P --> T[批次利润]
    P --> U[客户利润]
    P --> V[渠道利润]
    P --> W[门店利润]
```

### 报表建议

| 报表 | 用途 |
| --- | --- |
| 应收明细表 | 看谁欠我们钱 |
| 应付明细表 | 看我们欠谁钱 |
| 往来单位对账单 | 看某个客户/同行完整往来 |
| 折账明细表 | 看所有抵扣记录 |
| 收款明细表 | 看实际收了多少钱 |
| 付款明细表 | 看实际付了多少钱 |
| 经营费用表 | 看日常开支 |
| 资金账户流水表 | 看每个账户钱的进出 |
| 单机利润表 | 看每台机器赚多少钱 |
| 批次利润表 | 看一批货赚多少钱 |
| 门店利润表 | 看门店经营结果 |

## 11. 权限设计

```mermaid
flowchart TD
    A[员工角色] --> B[仓库]
    A --> C[销售]
    A --> D[财务]
    A --> E[财务主管]
    A --> F[老板/管理员]

    B --> B1[入库/出库/查看库存]
    C --> C1[创建销售单/查看客户账]
    D --> D1[收款/付款/费用录入/对账]
    E --> E1[折账审核/调账审核/作废审核]
    F --> F1[全部查看/权限配置/经营报表]
```

### 高风险权限

以下操作建议单独授权：

- 修改成本
- 修改销售价格
- 作废收款单
- 作废付款单
- 作废折账单
- 调账
- 删除或作废费用单
- 反审核
- 修改已出库资产
- 修改已结算单据
- 导出财务报表

## 12. 单据清单

| 单据 | 说明 |
| --- | --- |
| 应收单 | 客户/同行欠我们的钱 |
| 应付单 | 我们欠客户/供应商/同行的钱 |
| 收款单 | 实际收到钱 |
| 付款单 | 实际付出去钱 |
| 折账单 | 应收和应付互相抵扣 |
| 费用单 | 房租、水电、工资、物流等经营费用 |
| 退款单 | 退钱给客户 |
| 调账单 | 修正账务异常 |
| 资金流水 | 每笔资金变化 |
| 往来账流水 | 每个往来单位的账务变化 |

## 13. 财务审核问题清单

请财务重点确认以下问题：

1. 往来单位是否可以统一客户、供应商、同行？
2. 应收、应付、收款、付款的定义是否符合店内习惯？
3. 折账流程是否符合实际操作？
4. 折账是否需要审核？
5. 部分收款、部分付款是否常见？
6. 付款后改价应该怎么处理？
7. 收错款、付错款应该怎么处理？
8. 费用分类是否够用？
9. 哪些费用需要审批？
10. 哪些单据不能删除，只能红冲？
11. 资金账户需要哪些类型？
12. 是否需要按门店、员工、渠道统计利润？
13. 老板最关心哪些报表？
14. 月底对账需要导出哪些表？
15. 是否需要打印对账单给同行或客户确认？

第一版建议先做这些：

- 往来单位
- 应收单
- 应付单
- 收款单
- 付款单
- 折账单
- 费用单
- 资金账户
- 资金流水
- 往来账流水
- 应收应付报表
- 折账明细报表

后续再扩展：

- 费用分摊
