# 华网 OA 考勤快捷申报扩展

这是一个仅对 `oa.huawangsoft.com` 生效的 Chrome 扩展。地区和住宿地点会记住上一次的选择；每次只需修改工作概要，然后点击“保存考勤”。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择当前这个 `oa-attendance-extension` 文件夹。
5. 建议在 Chrome 工具栏的扩展菜单中，把“华网 OA 考勤快捷申报”固定到工具栏。

## 使用

1. 关闭代理，通过 Trust 打开并登录华网 OA。
2. 进入“个人办公 → 考勤申报 → 考勤录入”。
3. 页面右下角会出现“一键报考勤”按钮；也可以点击 Chrome 工具栏中的扩展图标。
4. 根据需要修改地区、工作概要和住宿地点。
5. 点击“保存考勤”直接提交。项目和工作状态使用 OA 当前默认值。

## 安全边界

- 扩展仅拥有 `oa.huawangsoft.com` 的网页访问权限。
- 不读取、保存或导出 Cookie、密码等登录信息。
- 登录会话由当前 OA 页面自动携带，不需要再次输入账号密码。
- 不直接拼接服务器请求，最终调用 OA 页面原有“保存”按钮，因此保留网站自己的校验和提交逻辑。
- 只自动填写地区、工作概要和住宿地点；项目、工作状态和费用使用 OA 当前默认值。
