不要直接点击绿色按钮。请在 Chrome 中打开本页，再把绿色按钮拖到 Chrome 书签栏。

一键报考勤
  1. 按 ⌘⇧B 显示 Chrome 书签栏。
  2. 把上面的绿色“一键报考勤”拖到书签栏；不要在本页直接点击。
  3. 关闭代理，通过 Trust 打开并登录 OA。
  4. 进入“个人办公 → 考勤申报 → 考勤录入”。
  5. 先在页面选择日期、项目、地区和住宿信息。
  6. 点击书签栏中的“一键报考勤”，填写工作概要并确认。

如果拖动安装不成功：点击“复制书签代码”，在 Chrome 新建一个书签，把复制的内容粘贴到书签的“网址”中。

脚本不会保存或导出登录 Cookie；真正提交前会展示完整摘要，并要求你再次确认。
