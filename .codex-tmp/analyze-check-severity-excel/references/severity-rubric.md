# 质检选项语义分级规则

## 目标

判断每个“选项文本”在对应“质检项上下文”下代表的业务严重程度。结果只写入建议列，不改写当前级别。

## 三级含义

- `正常`：明确表示完好、无故障、未发生负面事实，或处于该质检项的理想/合格区间。
- `一般`：存在轻微或中等程度瑕疵，但核心功能仍可使用，通常影响成色、体验或价格而非直接阻断交易。
- `异常`：核心功能不可用、严重损坏、重要部件缺失、锁定/进水/主板等高风险事实，或明显需要维修处理。

## 必须使用上下文

同一个词不能脱离问题判断：

- 上下文为“是否进水”时，`是/有`通常为异常，`否/无`为正常。
- 上下文为“功能是否正常”时，`是/正常`为正常，`否/不正常`为异常。
- `更换`、`维修`、`拆修`等词要结合部件和影响判断；重大部件或主板相关通常异常，轻微且不影响使用的外观件可为一般。
- `无`既可能表示“无故障”（正常），也可能表示“无配件/无功能”（异常），必须结合上下文。

## 同组选项比较

每次同时观察同一上下文的全部选项：

1. 识别理想端、轻微退化端和严重问题端。
2. 对百分比、区间、等级、次数等相对值，按该指标业务方向排序，不套用无依据的固定阈值。
3. 如果选项只有好/坏两端，可只使用正常和异常，不强行制造“一般”。
4. 如果存在轻微、中度、严重层级，轻微或中度通常为一般，严重为异常。

## 常见语义参考

- 通常正常：完好、正常、无异常、无拆修、未维修、原装、功能正常、显示正常、可正常使用。
- 通常一般：轻微划痕、轻微磕碰、轻微老化、一般磨损、局部色差、不影响使用的非核心瑕疵。
- 通常异常：碎裂、失灵、无法使用、缺失、进水、账号锁/激活锁、主板维修、不开机、无显示、严重变形。

这些只是语义参考，不是可直接替代上下文推理的关键词表。

## 待人工确认

以下情况不要猜：

- 上下文缺失，且选项是`是/否/有/无/其他`等依赖问题语义的词。
- 数值区间没有单位、方向或同组选项不足，无法判断高低优劣。
- 文本同时包含相互矛盾的状态。
- 行内容疑似错位、乱码或截断。

此时写：

- `建议级别`：空
- `确认状态`：`待确认`
- `标注备注`：说明缺少的判断依据，例如“上下文缺失，无法判断‘无’表示无故障还是无配件”。

## 输出说明

- 备注写业务理由，不写长篇推理过程。
- 推荐备注示例：`核心功能不可用`、`轻微外观磨损，不影响使用`、`明确表示无进水`。
- 不改变系统选项 ID、上下文、选项文本和当前级别。
