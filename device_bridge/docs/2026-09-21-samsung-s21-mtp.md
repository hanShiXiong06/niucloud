# 三星 S21 USB 只读探测记录

日期：2026-09-21；电脑：macOS Apple Silicon；设备：用户连接的三星 Galaxy S21 5G。

## 测试边界

- Python 标准库 `ctypes` 调用 libmtp 1.1.23，经 MTP 接口读取。
- 用户切换 USB 用途后，接口由 RNDIS 网络共享变为 MTP 文件传输。
- 已经用户同意临时停止原有 ADB 进程；本次没有使用 ADB。
- 手机仍暴露 ADB 接口，因此“手机关闭 USB 调试后的复测”尚未完成。
- 不读取或枚举照片、联系人、短信等用户内容，不执行设备重置、修改或删除，不创建业务数据。
- 最初探测使用临时目录中的 libmtp；后续 0.2.0 安装包验证见本文末尾。

## 实际读取结果

| 字段 | 实测值 | 使用边界 |
| --- | --- | --- |
| 制造商 | samsung | 型号映射的品牌上下文 |
| MTP 型号码 | SM-G9910 | 可用作型号库映射键，仍需确认对应叶子节点 |
| 设备友好名称 | Galaxy S21 5G | 可能被用户修改，不单独作为可靠型号键 |
| 原始设备版本 | G9910ZCUGHZE1 | 固件版本字符串，不能当作 Android 或 One UI 版本 |
| USB 序列号 | R5CR70…HWK | 与 MTP 标识不同，入库前需核对手机 SN |
| MTP 设备标识 | C15358…4D27 | 不能作为 IMEI 或未经核对的工厂 SN |
| 当前电量 | 59% | 会变化，不是健康度 |
| 存储名称 | 内部存储 | MTP 存储元数据 |
| MTP 可见总空间 | 242968653824 字节，约 226.28 GiB | 不是标称存储容量，不自动推算为 256GB |
| 剩余空间 | 232093499392 字节，约 216.15 GiB | 手机当时返回值 |
| 已用空间 | 10875154432 字节，约 10.13 GiB | 总空间减剩余空间，未枚举文件 |
| USB 连接速率 | 480000000 bit/s | 系统报告的连接速率，不是实测文件传输速度 |

基础读取约 0.09 秒；本次扩展读取约 0.47 秒，仅代表本台设备和本次电脑环境。

## 尚未得到的信息

IMEI/IMEI2、标称容量、RAM、机身颜色、电池健康度、循环次数、Android/One UI 版本，均未在本次设备基础属性读取中获得。

设备公布的 MTP 属性包括电量、设备友好名称、同步伙伴、设备类型、会话发起者和图像尺寸。协议的图像/文件属性不能当作这台手机的质检结果、屏幕参数或用户文件内容。

三星另暴露 USB 调制解调串口。尝试标准基础 `AT` 查询，2 秒内无回应，随即停止；未继续发送身份查询或任何配置命令。电脑串口参数已恢复、端口已关闭。

## 签收接入边界

- 最初探测仅为独立诊断脚本；后续已接入浏览器读取，但不自动保存业务数据或打印。
- 型号码与品牌可以用于后续型号库匹配；无唯一匹配时由签收员选择，不猜填。
- 两种设备标识分别保留；IMEI/SN 由现场核对，不能混用。
- 电量、MTP 空间归入读取档案，不填入健康度或商品容量字段。
- 本次结果不能推广为所有 Android 品牌均支持，也不代表 Windows 版本已验收。
- 16 项单元测试通过，包含存储未知值、容量含义、空字段及电量边界；没有新增数据库字段或修改框架。

## 0.2.0 Mac 桥集成验证

同日发现旧包问题：macOS 安装收据显示 0.1.2，但包内 PyInstaller 的版本常量及 17890 服务均为 0.1.1。不是浏览器缓存。旧服务只有 iPhone 读取，三星未被计入。

修复版本检查并构建 0.2.0，新增三星读取适配器，复用标准快照契约和已有型号映射。未新增表、字段或修改公共框架。动态库已随包携带，链接改为包内相对路径，不依赖客户安装 Homebrew。

- Python 集成入口：读取 1 台 S21，型号码 SM-G9910，USB SN 尾号 RHWK。
- PyInstaller 打包后的可执行程序：同样读取成功，版本 0.2.0，当前电量 100%。
- 28 项 Python 单元测试通过；前端编译、发行镜像一致性和安卓映射检查通过。
- IMEI、颜色、容量、健康度、循环次数、Android 版本保持空白；未读取用户文件。
- 新包 `hsx_device_bridge-0.2.0-macos-arm64.pkg` 已本地生成，未上传 GitHub；Windows 安卓读取尚未实现或验收。
- 用户已完成覆盖安装。安装收据为 0.2.0，17890 的 `/v1/health` 返回版本 0.2.0、`android_mtp: true`、1 台设备、无扫描错误；携带本机网页 Origin 请求 `/v1/devices` 成功读取同一 S21，约 0.28 秒。此为安装后实机接口验收，未提交订单或测试真实打印。
- 手机完全关闭 USB 调试后的复测、多台设备并发实测、其他安卓品牌和其他 Mac 版本仍待验证。
